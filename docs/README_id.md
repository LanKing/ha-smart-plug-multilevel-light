# 🔌 Lampu Multi-Level Smart Plug

![Пример режимов на карточке](ha-smart-plug-multilevel-light-card-modes-v4.png)

**✨ Fitur dan fitur:**

* Membuat entitas Home Assistant asli`light`kompatibel dengan otomatisasi, skrip, dan antarmuka HA standar;
* Menyalakan lampu dengan benar terlepas dari cara mematikannya: jika daya dimatikan melalui soket pintar, lampu akan langsung menyala; jika lampu dimatikan dengan tombolnya sendiri saat soket menyala, lampu melakukan siklus mematikan energi dan menyalakannya kembali;
* Secara otomatis menentukan mode pengoperasian lampu saat ini berdasarkan daya stabil yang diukur secara aktual;
* Ia memiliki konfigurator sederhana di mana pengguna secara berurutan memberi nama mode yang didukung oleh lampunya, dan sistem belajar dengan menentukan daya stabil di setiap mode;
* Selama pengaturan pertama, daya dibaca secara real time: pengguna hanya perlu mengalihkan lampu ke mode berikutnya dan menekan tombol belajar;
* Berhasil menyaring pembacaan daya yang tidak stabil, mencegah perubahan kacau pada indikator pada kartu ketika daya “melompat” dalam satu mode (dan bahkan bertepatan dengan mode berikutnya);
* Mendukung sejumlah mode;
* Kartu ini dibuat di atas Kartu Ubin Asisten Rumah standar, mempertahankan geometri, latar belakang, efek hover, ukuran, tipografi, dan tindakan standarnya;
* Di dalam kartu, kecerahan saat ini dikodekan secara visual berdasarkan intensitas warna;
* Menghitung kecerahan secara linier relatif terhadap daya maksimum; pembulatan kecerahan yang dihitung hingga 5% dapat diaktifkan untuk tampilan persentase yang lebih akurat;
* Memungkinkan Anda menyesuaikan secara fleksibel parameter yang ditampilkan dan tampilan kartu;
* Memungkinkan Anda memilih hanya sensor daya yang terkait dengan smart plug yang dipilih;
* Memungkinkan Anda menyesuaikan penundaan siklus de-energisasi untuk pengoperasian yang benar dengan berbagai model lampu dan soket;
* Memungkinkan Anda menyetel ambang daya di bawah batas mana lampu dianggap mati;
* Antarmuka dilokalkan untuk 64 lokasi Home Assistant.

## 🗜 Mempersiapkan setrika

Anda akan membutuhkan:

1. Soket pintar yang seharusnya menyediakan kontrol daya (saklar) dan pengukuran daya (sensor dengan kelas\_perangkat: daya) ke HA. Kedua entitas harus berada pada perangkat yang sama dan diaktifkan.
2. Lampu konyol yang menyala secara otomatis setelah dicolokkan dan memiliki beberapa pengaturan kecerahan untuk kenikmatan penuh.

> Saya menggunakan soket[Tuya TS011F (dalam kasus Girier)](https://www.zigbee2mqtt.io/devices/TS011F_plug_3.html). Saya akan mengatakan bahwa pada awal percobaan, rangkaian soket Girier tidak cocok karena pengukuran yang tidak akurat, tetapi model ini cocok, meskipun demikian juga dalam kasus Girier.

### 👨‍🔬 Pengaturan penting yang saya terapkan pada outlet saya:

> Soket saya tidak secara otomatis melaporkan pembacaan ke HA dan hanya mengizinkan polling pada interval tertentu. Secara default, itu adalah 60 detik. Interval ini perlu diatur ke 1 detik, jika tidak, Anda akan menunggu sangat lama hingga tampilan peralihan mode muncul.

Deskripsi ini hanya relevan untuk pemilik soket yang terhubung melalui Z2M. Pengguna lain harus menyesuaikan kecepatan refresh dalam konfigurasi mereka:

1. Membuka**Asisten Rumah → Zigbee2MQTT**. Jika Zigbee2MQTT tidak ada di menu samping, buka**Pengaturan → Aplikasi → Zigbee2MQTT → Buka antarmuka web**.
2. Pergi ke bagian**Perangkat**.
3. Pilih outlet yang diperlukan.
4. Buka tabnya**Pengaturan (khusus)**.
5. Perubahannya**Interval jajak pendapat pengukuran**pada 1 detik.

## 📦 Instalasi

### 🛍 Instalasi melalui HACS

ℹ️[Apa itu HACS dan bagaimana cara menginstalnya?](https://github.com/LanKing/ha-tools/blob/main/appendix-what-is-hacs/docs/README_id.md)

🚀[Coba tambahkan repositori di tautan](https://my.home-assistant.io/redirect/hacs_repository/?owner=LanKing\&repository=ha-smart-plug-multilevel-light\&category=integration). Jika HA Anda mendukung metode ini, klik**Menambahkan**di jendela yang terbuka, lalu tombol**Unduh**di pojok kanan bawah. Jika instalasi berhasil diselesaikan, Anda dapat melewati langkah selanjutnya. Lewati langsung ke bagian[mulai cepat](#getting-started).

#### 1. Menambahkan repositori

Meskipun repositori tidak termasuk dalam direktori HACS standar, tambahkan sebagai direktori khusus:

1. Membuka**HACS → Integrasi**.
2. Buka menu di pojok kanan atas dan pilih**Repositori Khusus**.
3. Menambahkan:

```text
https://github.com/LanKing/ha-smart-plug-multilevel-light
```

4. Pilih jenis**Integrasi**dan tekan**Menambahkan**.

> Menambahkan repositori hanya membuat integrasi tersedia di HACS. Untuk menginstal, Anda perlu membuka kartunya secara terpisah dan klik**Unduh**.

#### 2. Pemasangan integrasi

1. Cari di HACS:`Smart Plug Multi-Level Light`.
2. Buka integrasi dan klik**Unduh**.
3. Setelah instalasi, restart Home Assistant sepenuhnya.

<a id="manual-installation"></a>

### 🧑‍💻 Instalasi tanpa HACS

1. Pada halaman repositori, klik**Kode → Unduh ZIP**.
2. Buka kemasan arsip.
3. Salin foldernya:

```text
custom_components/smart_plug_multilevel_light
```

ke direktori konfigurasi Home Assistant:

```text
/config/custom_components/smart_plug_multilevel_light
```

Jalur file terakhir`manifest.json`akan terlihat seperti ini:

```text
/config/custom_components/smart_plug_multilevel_light/manifest.json
```

4. Mulai ulang Home Assistant sepenuhnya.

> Jangan menyalin seluruh folder repositori eksternal ke`custom_components`. Di dalam`custom_components`foldernya harus ditempatkan secara langsung`smart_plug_multilevel_light`.

Kartu tersebut termasuk dalam integrasi, jadi HACS tidak diperlukan untuk menginstalnya. Setelah menyalin file secara manual, memulai ulang Home Assistant, dan membuat objek pembantu pertama, integrasi menerbitkan file kartu JavaScript dan secara otomatis mendaftarkannya dengan sumber daya panel dalam mode standar`storage`. Dalam mode sumber daya YAML, kartu harus didaftarkan secara manual, seperti dijelaskan di bawah.

## 🚀 Mulai cepat setelah instalasi

### 🛠 Konfigurasi

1. Membuk&#x61;**[Pengaturan → Perangkat dan layanan → Aksesori](https://my.home-assistant.io/redirect/helpers/)**&#x64;an tekan**Buat Objek Pembantu**.

2. Memilih**Lampu Multi-Level Steker Cerdas**.

3. Pilih smart plug yang terhubung dengan lampu. Daftar tersebut hanya menampilkan outlet tempat Home Assistant melihat sensor daya di perangkat yang sama.

4. Pada langkah selanjutnya, atur parameter lampu:
   * **Nama lampu (Light name)**— nama entitas yang dibuat, misalnya`FloorLamp`;
   * **Power sensor**- sensor daya soket;

5. Di bagian**ZUI003Z**tambahkan setidaknya satu mode kecerahan dengan mengklik**Menambahkan**.<br /> <img src="modes-edit.png" width="465"/>Ganti lampu dengan tombol fisiknya, masukkan nama mode dan mulai**Test stable power**. Setelah mendapatkan nilai stabil, tekan**Menerapkan**.

6. Setelah menambahkan mode pertama, tambahkan mode lainnya dengan mengulangi langkah-langkah ini. Anda akan mendapatkan sesuatu seperti:<br />
   <img src="modes-list.png" width="457"/>

7. Simpan objek pembantu. Home Assistant akan membuat entitas baru`light`, Misalnya`light.FloorLamp`.

### 🧩 Kartu Lovelace

1. Buka panel yang diinginkan, aktifkan mode edit dan klik**Tambahkan kartu**.
2. Memilih**Lampu Multi-Level Steker Cerdas**, tentukan entitas yang dibuat`light`dan simpan kartunya.

Jika kartu tersebut tidak termasuk yang tersedia, Anda mungkin menggunakannya[Mode YAML sumber daya Lovelace](#yaml-lovelace-mode).

### 🎨 Efek visual

#### Pengaturan di kartu

Buka panel tempat kartu berada, masuk ke mode edit dan klik**Sunting**pada kartu yang diinginkan.

Membuka bagian**Konten (Content)**, Anda akan melihat pengaturan yang tersedia:

* **Tampilkan nama mode (Show mode name)**— menampilkan atau menyembunyikan nama mode saat ini: misalnya, Redup, Rendah, Sedang, atau Tinggi.
* **Tampilkan persentase (Show percentage)**— menampilkan atau menyembunyikan kecerahan yang dihitung sebagai persentase.

Membuka bagian**Interaksi (Interactions)**, Anda akan melihat:

* **Selalu tampilkan latar ikon (Always show icon background)**— mempertahankan latar belakang bulat di sekitar ikon, meskipun tindakan terpisah untuk ikon tersebut dinonaktifkan.

> 🚫 Ngomong-ngomong, jika Anda, seperti saya, menggunakan ikon kartu non-standar dan ketika dimatikan tidak dicoret secara visual, saya merekomendasikan plugin saya yang lain -[Mdi Mati Mundur](https://github.com/LanKing/ha-mdi-off-fallback/blob/main/docs/README_id.md), yang memecahkan masalah estetika ini.

#### Kecerahan dibulatkan hingga 5%

Membuk&#x61;**[Pengaturan → Perangkat dan layanan → Aksesori](https://my.home-assistant.io/redirect/helpers/)**, temukan objek pembantu yang dibuat sebelumnya**Lampu Multi-Level Steker Cerdas**dan buka pengaturannya. Hidupkan atau matikan**Round brightness to 5% (may look nicer)**.

Jika pengaturan diaktifkan, persentase yang dihitung akan dibulatkan ke 5% terdekat, misalnya: 33% → 35%, 67% → 65%.

Pembulatan hanya mempengaruhi persentase yang ditampilkan dan intensitas visual kartu. Definisi mode dan pengoperasian lampu tidak berubah. Secara default, pembulatan dinonaktifkan.

## 🧩 Kartu Lovelace secara detail

Opsi yang tersedia:

| Parameter | Ketik | Bawaan | Deskripsi |
|---|---|---:|---|
| `entity` | string | diperlukan | entitas yang diciptakan oleh integrasi |
| `name` | string | nama entitas | menimpa nama yang tertera pada kartu |
| `icon` | string | ikon entitas | menimpa ikon |
| `show_mode` | boolean | `true` | menunjukkan nama mode |
| `show_percentage` | boolean | `true` | menunjukkan persentase sintetik |
| `icon_tap_action` | action | `more-info` | tindakan tambahan saat ikon diketuk |
| `always_show_icon_background` | boolean | `false` | selalu menampilkan latar belakang ikon lingkaran, meskipun None dipilih untuk icon_tap_action |

Contoh lengkap:

```yaml
type: custom:smart-plug-multilevel-light-card
entity: light.floor_lamp
name: Торшер
icon: mdi:floor-lamp
show_mode: true
show_percentage: true
icon_tap_action:
  action: more-info
always_show_icon_background: false
```

<a id="yaml-lovelace-mode"></a>

### Mode YAML sumber daya Lovelace

> Kemungkinan besar, Anda tidak mengaktifkan mode ini. Jika tidak ada masalah dan kartu berfungsi, lewati langkah ini.

kalau sudah`configuration.yaml`ditetapkan secara eksplisit:

```yaml
lovelace:
  resource_mode: yaml
```

Home Assistant tidak mengizinkan integrasi untuk mengubah daftar sumber daya secara otomatis. Dalam hal ini, tambahkan sumber daya secara manual:

```yaml
lovelace:
  resource_mode: yaml
  resources:
    - url: /api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
      type: module
```

Setelah perubahan, reboot sumber daya Lovelace atau mulai ulang Home Assistant.

<a id="troubleshooting"></a>

## 🧯 Pemecahan masalah

<details>
<summary><b>❓Integrasi tidak muncul di daftar pembantu</b></summary>
<br />

**Kemungkinan penyebabnya:**&#x6A;alur yang salah atau Home Assistant tidak dimulai ulang.

Periksa ketersediaan file:

```text
/config/custom_components/smart_plug_multilevel_light/manifest.json
```

Kemudian lakukan restart penuh Home Assistant dan periksa kesalahan pada log`smart_plug_multilevel_light`.

<hr />
</details>

<details>
<summary><b>❓Daftar steker kosong</b></summary>
<br />

Integrasi hanya menampilkan objek`switch`terkait dengan perangkat yang juga menyediakan sensor yang disertakan`device_class: power`.

Lapor masu&#x6B;**[Pengaturan → Perangkat dan layanan → Objek](https://my.home-assistant.io/redirect/entities/)**:

* Apakah mereka termasuk?`switch`dan sensor daya untuk satu perangkat?
* Apakah sensor daya dihidupkan?
* Apakah ini ditentukan dengan benar?`device_class`?
* Apakah ia memiliki status numerik?

<hr />
</details>

<details>
<summary><b>❓Pembuatan berhenti karena pesan sensor daya hilang</b></summary>
<br />

Setelah memilih stopkontak, integrasi memeriksa kembali keberadaan sensor daya. Kesalahan terjadi jika sensor telah dilepas, dinonaktifkan, dipindahkan ke perangkat lain, atau sudah tidak ada lagi`device_class: power`.

<hr />
</details>

<details>
<summary><b>❓Lampu ditampilkan sebagai Mati saat steker menyala</b></summary>
<br />

Periksa nilai sensor daya. Lampu virtual dianggap mati ketika`0 W`; bila positif, itu harus didefinisikan sebagai`on`.

<hr />
</details>

<details>
<summary><b>❓Lampu ditampilkan dalam keadaan Hidup saat mati secara fisik</b></summary>
<br />

Periksa apakah sensor daya yang dipilih benar-benar ditampilkan`0 W`, saat lampu dimatikan dengan tombolnya sendiri.

<hr />
</details>

<details>
<summary><b>❓Mode yang salah terdeteksi</b></summary>
<br />

Memeriksa**🐞 Last measures**dalam pengaturan dan atribut`power_history`,`power_history_modes`,`power_sample_interval_seconds`Dan`selected_power_mode`.`power_history`menunjukkan nilai daya terakhir yang tercatat,`power_history_modes`— mode untuk masing-masingnya sesuai dengan ambang batas yang dikonfigurasi,`power_sample_interval_seconds`adalah interval fiksasi periodik, dan`selected_power_mode`— mode terkonfirmasi saat ini.

<hr />
</details>

<details>
<summary><b>❓Perubahan mode tidak langsung ditampilkan</b></summary>
<br />

Ini adalah perilaku yang diharapkan. Untuk mencegah fluktuasi daya jangka pendek yang menyebabkan peralihan palsu, integrasi hanya mengubah mode setelah beberapa pembacaan berturut-turut sesuai dengan mode baru yang sama.

Jumlah pembacaan yang diperlukan ditentukan oleh parameter**Consecutive readings to switch**dan defaultnya adalah`5`. Pengukuran berkala dilakukan satu kali per detik, dan perubahan status sensor segera diproses. Jika selama pengujian nilainya sesuai dengan mode yang berbeda, hitungan mundur akan dimulai lagi.

Hingga konfirmasi, integrasi mempertahankan mode sebelumnya. Berkat ini, kartu tidak berpindah antar mode karena nilai antara yang terjadi saat mengganti lampu, menstabilkan dayanya, atau fluktuasi kecil dalam pembacaan sensor.

Mengurangi jumlah pembacaan akan mempercepat tampilan mode baru, namun membuat deteksi lebih sensitif terhadap fluktuasi daya.

<hr />
</details>

<details>
<summary><b>❓Kartu tersebut tidak muncul dalam daftar</b></summary>
<br />

Pendaftaran otomatis terjadi hanya setelah memuat setidaknya satu objek pembantu yang dikonfigurasi dan hanya dalam mode sumber daya`storage`. Metode menginstal integrasi - melalui HACS atau secara manual - tidak mempengaruhi hal ini.

Memeriks&#x61;**[Pengaturan → Panel → ⋮ → Sumber Daya](https://my.home-assistant.io/redirect/lovelace_resources/)**. URL-nya harus ada di sana:

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

Dalam mode YAML[menambahkan sumber daya secara manual](#yaml-lovelace-mode).

<hr />
</details>

<details>
<summary><b>❓Kartu lama masih ditampilkan setelah pembaruan</b></summary>
<br />

1. Mulai ulang Home Assistant sepenuhnya.
2. Refresh halaman untuk menghapus cache browser Anda.
3. Periksa nomor versi di URL sumber daya panel.
4. Di aplikasi seluler, tutup sepenuhnya dan buka kembali antarmuka.

<hr />
</details>

## 🗑 Penghapusan

1. Hapus semua objek pembantu yang dibuat**Lampu Multi-Level Steker Cerdas**melalu&#x69;**[Pengaturan → Perangkat dan layanan → Aksesori](https://my.home-assistant.io/redirect/helpers/)**.
2. Hapus integrasi melalui HACS atau hapus folder secara manual:

```text
/config/custom_components/smart_plug_multilevel_light
```

3. Memeriks&#x61;**[Pengaturan → Panel → ⋮ → Sumber Daya](https://my.home-assistant.io/redirect/lovelace_resources/)**&#x64;an hapus sumber daya kartu secara manual jika masih ada:

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

4. Mulai ulang Home Assistant sepenuhnya.
5. Jika perlu, segarkan halaman untuk menghapus cache antarmuka.
