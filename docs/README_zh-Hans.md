# 🔌 智能插头多级灯

![Пример режимов на карточке](ha-smart-plug-multilevel-light-card-modes-v4.png)

**✨ 特点及特点：**

* 创建本机 Home Assistant 实体`light`与自动化、脚本和标准 HA 接口兼容；
* 无论灯是如何关闭的，都能正确打开灯：如果通过智能插座关闭电源，则只需将其打开；如果在插座打开时用自己的按钮关闭灯，则会执行断电和再次打开的循环；
* 根据实测稳定功率自动判断灯具当前工作模式；
* 它有一个简单的配置器，用户可以在其中按顺序命名其灯支持的模式，系统通过确定每种模式下的稳定功率来学习；
* 首次设置时，实时读取电量：用户只需将灯切换到下一个模式并按下学习按钮即可；
* 成功过滤掉不稳定的功率读数，防止功率在一种模式下“跳跃”时（甚至与下一种模式重合）时卡上指示灯出现混乱变化；
* 支持任意数量的模式；
* 该卡建立在标准家庭助理磁贴卡之上，保留其几何形状、背景、悬停效果、尺寸、排版和标准操作；
* 在卡中，当前亮度通过颜色强度进行视觉编码；
* 相对于最大功率线性计算亮度；可以将计算出的亮度四舍五入到 5%，以便更准确地显示百分比；
* 允许您灵活定制卡片的显示参数和外观；
* 允许您仅选择与所选智能插头相关的功率传感器；
* 允许您调整断电周期的延迟，以正确操作不同型号的灯具和插座；
* 允许您设置功率阈值，低于该阈值灯将被视为关闭；
* 该界面针对 64 个 Home Assistant 区域设置进行了本地化。

## 🗜 准备铁

您将需要：

1. 智能插座，应向 HA 提供电源控制（开关）和电源测量（具有 device\_class：电源的传感器）。两个实体必须属于同一设备并且已启用。
2. 一种傻乎乎的灯，一旦插入电源就会自动打开，并具有多种亮度设置，让您尽享享受。

> 我用了一个插座[涂鸦 TS011F（Girier 箱）](https://www.zigbee2mqtt.io/devices/TS011F_plug_3.html)。我要说的是，在实验开始时，由于测量不准确，Girier系列插座不适合，但这个模型适合，尽管它也在Girier案例中。

### 👨‍🔬 我应用于我的插座的重要设置：

> 我的套接字不会自动向 HA 报告读数，并且只允许按指定的时间间隔进行轮询。默认情况下为 60 秒。有必要将此间隔设置为1秒，否则您将等待很长时间才能出现模式切换显示。

此描述仅与通过 Z2M 连接的套接字的所有者相关。其他用户应在其配置中调整刷新率：

1. 打开**家庭助理 → Zigbee2MQTT**。如果 Zigbee2MQTT 不在侧面菜单中，请打开**设置 → 应用程序 → Zigbee2MQTT → 打开 Web 界面**.
2. 转到部分**设备**.
3. 选择所需的插座。
4. 打开选项卡**设置（具体）**.
5. 变化**测量轮询间隔**1 秒。

## 🚀 安装后快速启动

### 🛠 配置

1. 打&#x5F00;**[设置 → 设备和服务 → 配件](https://my.home-assistant.io/redirect/helpers/)**&#x5E76;按**创建辅助对象**.

2. 选择**智能插头多级灯**.

3. 选择灯所连接的智能插头。该列表仅显示 Home Assistant 在同一设备中看到功率传感器的插座。

4. 在下一步中，设置灯参数：
   * **灯光名称 (Light name)**— 例如，正在创建的实体的名称`FloorLamp`;
   * **Power sensor**- 插座功率传感器；

5. 在本节中**ZUI003Z**单击添加至少一种亮度模式**添加**.<br /> <img src="modes-edit.png" width="465"/>用物理按钮开关灯，输入模式名称并启动**Test stable power**。获得稳定值后，按**申请**.

6. 添加第一个模式后，重复这些步骤添加其余模式。你最终应该得到类似的结果：<br />
   <img src="modes-list.png" width="457"/>

7. 保存辅助对象。 Home Assistant 将创建一个新实体`light`， 例如`light.FloorLamp`.

### 🧩 洛夫莱斯卡

1. 打开所需的面板，打开编辑模式并单击**添加卡**.
2. 选择**智能插头多级灯**,指定创建的实体`light`并保存该卡。

如果该卡不在可用卡中，您可能正在使用[Lovelace资源YAML模式](#yaml-lovelace-mode).

### 🎨 视觉效果

#### 卡内设置

打开卡片所在面板，进入编辑模式，点击**编辑**位于所需的卡上。

打开该部分**内容 (Content)**，您将看到可用的设置：

* **显示模式名称 (Show mode name)**— 显示或隐藏当前模式的名称：例如，暗淡、低、中或高。
* **显示百分比 (Show percentage)**— 以百分比形式显示或隐藏计算出的亮度。

打开该部分**交互 (Interactions)**，你会看到：

* **始终显示图标背景 (Always show icon background)**— 保留图标周围的圆形背景，即使禁用了单独的操作。

> 🚫 顺便说一句，如果您像我一样使用非标准卡片图标，并且关闭时它不会在视觉上被划掉，我推荐我的另一个插件 -[Mdi 关闭后备](https://github.com/LanKing/ha-mdi-off-fallback/blob/main/docs/README_zh-Hans.md)，这就解决了这个审美问题。

#### 亮度四舍五入至 5%

打&#x5F00;**[设置 → 设备和服务 → 配件](https://my.home-assistant.io/redirect/helpers/)**，找到之前创建的辅助对象**智能插头多级灯**并打开其设置。打开或关闭**Round brightness to 5% (may look nicer)**.

启用该设置后，计​​算出的百分比将四舍五入到最接近的 5%，例如：33% → 35%、67% → 65%。

四舍五入仅影响卡片的显示百分比和视觉强度。灯的模式定义和操作不会改变。默认情况下，舍入是禁用的。

## 🧩 Lovelace 卡详细信息

可用选项：

| 参数 | 类型 | 默认 | 描述 |
|---|---|---:|---|
| `entity` | string | 必填 | 集成创建的实体 |
| `name` | string | 实体名称 | 覆盖卡上显示的姓名 |
| `icon` | string | 实体图标 | 覆盖图标 |
| `show_mode` | boolean | `true` | 显示模式名称 |
| `show_percentage` | boolean | `true` | 显示合成百分比 |
| `icon_tap_action` | action | `more-info` | 点击图标时的附加操作 |
| `always_show_icon_background` | boolean | `false` | 始终显示圆形图标背景，即使为 icon_tap_action 选择 None 也是如此 |

完整示例：

```yaml
type: custom:smart-plug-multilevel-light-card
entity: light.floor_lamp
name: Торшер
icon: mdi:floor-lamp
show_mode: true
show_percentage: true
icon_tap_action:
  action: more-info
always_show_icon_background: false
```

<a id="yaml-lovelace-mode"></a>

### Lovelace资源YAML模式

> 最有可能的是，您没有启用此模式。如果没有问题并且卡工作正常，请跳过此步骤。

如果你有`configuration.yaml`明确设置：

```yaml
lovelace:
  resource_mode: yaml
```

Home Assistant 不允许集成自动更改资源列表。在这种情况下，请手动添加资源：

```yaml
lovelace:
  resource_mode: yaml
  resources:
    - url: /api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
      type: module
```

更改后，重新启动 Lovelace 资源或重新启动 Home Assistant。

集成仅显示对象`switch`与还提供附带传感器的设备相关联`device_class: power`.

报&#x5230;**[设置 → 设备和服务 → 对象](https://my.home-assistant.io/redirect/entities/)**:

* 他们属于吗`switch`和一台设备的功率传感器？
* 功率传感器是否打开？
* 指定是否正确？`device_class`?
* 它有数字状态吗？

<hr />
</details>

<details>
<summary><b>❓创建因缺少功率传感器消息而停止</b></summary>
<br />

选择插座后，集成会重新检查是否存在功率传感器。如果传感器已被移除、禁用、移至其他设备或不再具有，则会发生错误`device_class: power`.

<hr />
</details>

<details>
<summary><b>❓插头打开时灯显示为关闭</b></summary>
<br />

检查功率传感器值。虚拟灯被认为关闭时`0 W`;当为正时，应定义为`on`.

<hr />
</details>

<details>
<summary><b>❓灯在物理关闭时显示为打开</b></summary>
<br />

检查所选功率传感器是否实际显示`0 W`，当灯通过其自身的按钮关闭时。

<hr />
</details>

<details>
<summary><b>❓检测到错误模式</b></summary>
<br />

查看**🐞 Last measures**在设置和属性中`power_history`,`power_history_modes`,`power_sample_interval_seconds`和`selected_power_mode`.`power_history`显示最后记录的功率值，`power_history_modes`— 根据配置的阈值每个人的模式，`power_sample_interval_seconds`是周期性注视的间隔，并且`selected_power_mode`— 当前确认模式。

<hr />
</details>

<details>
<summary><b>❓模式更改不会立即显示</b></summary>
<br />

这是预期的行为。为了防止短期功率波动引起杂散切换，积分仅在多个连续读数对应于相同的新模式后才改变模式。

所需的读数数量由参数设置**Consecutive readings to switch**并默认为`5`。每秒执行一次定期测量，并立即处理传感器状态的变化。如果在测试期间该值对应于不同的模式，则倒计时再次开始。

在确认之前，集成保持之前的模式。因此，该卡不会因切换灯时出现的中间值、稳定其功率或传感器读数的小波动而在模式之间切换。

减少读数的数量加快了新模式的显示速度，但使检测对功率波动更加敏感。

<hr />
</details>

<details>
<summary><b>❓该卡未出现在列表中</b></summary>
<br />

仅在加载至少一个已配置的辅助对象后且仅在资源模式下才会发生自动注册`storage`。安装集成的方法（通过 HACS 或手动）不会影响这一点。

查&#x770B;**[设置 → 面板 → ⋮ → 资源](https://my.home-assistant.io/redirect/lovelace_resources/)**。 URL 应该在那里：

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

在 YAML 模式下[手动添加资源](#yaml-lovelace-mode).

<hr />
</details>

<details>
<summary><b>❓更新后仍显示旧卡</b></summary>
<br />

1. 完全重新启动家庭助理。
2. 刷新页面以清除浏览器缓存。
3. 检查面板资源 URL 中的版本号。
4. 在移动应用程序中，完全关闭并重新打开界面。

<hr />
</details>

## 🗑 移除

1. 删除所有创建的辅助对象**智能插头多级灯**通&#x8FC7;**[设置 → 设备和服务 → 配件](https://my.home-assistant.io/redirect/helpers/)**.
2. 通过 HACS 删除集成或手动删除文件夹：

```text
/config/custom_components/smart_plug_multilevel_light
```

3. 查&#x770B;**[设置 → 面板 → ⋮ → 资源](https://my.home-assistant.io/redirect/lovelace_resources/)**&#x5982;果还有的话，手动删除卡片资源：

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

4. 完全重新启动家庭助理。
5. 如有必要，请刷新页面以清除界面缓存。
