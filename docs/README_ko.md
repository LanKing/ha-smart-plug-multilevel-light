# 🔌 스마트 플러그 다단계 조명

![Пример режимов на карточке](https://raw.githubusercontent.com/LanKing/ha-smart-plug-multilevel-light/main/docs/ha-smart-plug-multilevel-light-card-modes-v4.png)

**✨ 특징 및 특징:**

* 네이티브 홈어시스턴트 엔터티를 생성합니다.`light`자동화, 스크립트 및 표준 HA 인터페이스와 호환됩니다.
* 램프가 꺼진 방식에 관계없이 램프가 올바르게 켜집니다. 스마트 소켓을 통해 전원이 꺼진 경우 간단히 켜집니다. 소켓이 켜져 있는 동안 자체 버튼으로 램프가 꺼지면 전원이 꺼졌다가 다시 켜지는 과정을 수행합니다.
* 실제로 측정된 안정적인 전력을 기반으로 램프의 현재 작동 모드를 자동으로 결정합니다.
* 여기에는 사용자가 램프가 지원하는 모드의 이름을 순차적으로 지정하는 간단한 구성 기능이 있으며 시스템은 각 모드의 안정적인 전력을 결정하여 학습합니다.
* 첫 번째 설정에서는 전원이 실시간으로 판독됩니다. 사용자는 조명을 다음 모드로 전환하고 학습 버튼을 누르기만 하면 됩니다.
* 불안정한 전력 판독값을 성공적으로 필터링하여 한 모드 내에서 전력이 "점프"할 때(심지어 다음 모드와도 일치할 때) 카드 표시기가 혼란스럽게 변경되는 것을 방지합니다.
* 임의의 수의 모드를 지원합니다.
* 카드는 표준 홈어시스턴트 타일 카드 위에 구축되어 기하학, 배경, 호버 효과, 크기, 타이포그래피 및 표준 동작을 유지합니다.
* 카드에서는 현재 밝기가 색상 강도에 따라 시각적으로 인코딩됩니다.
* 최대 전력을 기준으로 밝기를 선형적으로 계산합니다. 보다 정확한 백분율 표시를 위해 계산된 밝기를 5%로 반올림할 수 있습니다.
* 표시된 매개변수와 카드의 모양을 유연하게 사용자 정의할 수 있습니다.
* 선택한 스마트 플러그와 관련된 전원 센서만 선택할 수 있습니다.
* 다양한 램프 및 소켓 모델의 올바른 작동을 위해 전원 차단 주기의 지연을 조정할 수 있습니다.
* 램프가 꺼진 것으로 간주되는 전력 임계값을 설정할 수 있습니다.
* 인터페이스는 64개 홈어시스턴트 로캘에 맞게 현지화되었습니다.

## 🗜 다리미 준비하기

다음이 필요합니다.

1. HA에 전원 제어(스위치) 및 전원 측정(device\_class: 전원이 포함된 센서)을 제공해야 하는 스마트 소켓입니다. 두 엔터티 모두 동일한 장치에 속해야 하며 활성화되어야 합니다.
2. 전원을 연결하면 자동으로 켜지고 다양한 밝기 설정을 통해 완벽한 즐거움을 선사하는 재미있는 조명입니다.

> 소켓을 사용했어요[Tuya TS011F(Girier 케이스)](https://www.zigbee2mqtt.io/devices/TS011F_plug_3.html). 실험 초기에는 Girier 시리즈 소켓이 부정확한 측정으로 인해 맞지 않았지만 이 모델은 Girier 케이스에도 불구하고 적합했습니다.

### 👨‍🔬 내 콘센트에 적용한 중요한 설정:

> 내 소켓은 판독값을 HA에 자동으로 보고하지 않으며 지정된 간격으로만 폴링을 허용합니다. 기본적으로 60초였습니다. 이 간격을 1초로 설정해야 합니다. 그렇지 않으면 모드 전환 표시가 나타날 때까지 매우 오랜 시간을 기다려야 합니다.

이 설명은 Z2M을 통해 연결된 소켓 소유자에게만 해당됩니다. 다른 사용자는 구성 내에서 새로 고침 빈도를 조정해야 합니다.

1. 열려 있는**홈어시스턴트 → Zigbee2MQTT**. Zigbee2MQTT가 사이드 메뉴에 없으면 다음을 엽니다.**설정 → 애플리케이션 → Zigbee2MQTT → 웹 인터페이스 열기**.
2. 섹션으로 이동**장치**.
3. 필요한 콘센트를 선택하십시오.
4. 탭 열기**설정(구체적)**.
5. 변경 사항**측정 폴링 간격**1초에.

🚀[링크에 저장소를 추가해 보세요](https://my.home-assistant.io/redirect/hacs_repository/?owner=LanKing\&repository=ha-smart-plug-multilevel-light\&category=integration). HA가 이 방법을 지원하는 경우**추가하다**열리는 창에서 버튼을 클릭하세요.**다운로드**오른쪽 하단에 있습니다. 설치가 성공적으로 완료되면 추가 단계를 건너뛸 수 있습니다. 섹션으로 바로 건너뛰기[빠른 시작](#getting-started).

#### 1. 저장소 추가

저장소는 표준 HACS 디렉터리에 포함되어 있지 않지만 사용자 지정 디렉터리로 추가합니다.

1. 열려 있는**HACS → 통합**.
2. 오른쪽 상단의 메뉴를 열고 다음을 선택하세요.**사용자 정의 저장소**.
3. 추가하다:

```text
https://github.com/LanKing/ha-smart-plug-multilevel-light
```

4. 유형 선택**완성**그리고 누르세요**추가하다**.

> 저장소를 추가하면 HACS에서만 통합이 가능해집니다. 설치하려면 별도로 카드를 열고 클릭해야 합니다.**다운로드**.

#### 2. 통합 설치

1. HACS에서 검색:`Smart Plug Multi-Level Light`.
2. 통합을 열고 클릭하세요.**다운로드**.
3. 설치 후 홈어시스턴트를 완전히 다시 시작하세요.

<a id="manual-installation"></a>

### 🧑‍💻 HACS 없이 설치

1. 저장소 페이지에서**코드 → ZIP 다운로드**.
2. 아카이브의 압축을 풀어보세요.
3. 폴더를 복사합니다.

```text
custom_components/smart_plug_multilevel_light
```

홈어시스턴트 구성 디렉토리에:

```text
/config/custom_components/smart_plug_multilevel_light
```

최종 파일 경로`manifest.json`다음과 같아야 합니다:

```text
/config/custom_components/smart_plug_multilevel_light/manifest.json
```

4. 홈어시스턴트를 완전히 다시 시작하세요.

> 전체 외부 저장소 폴더를 복사하지 마십시오.`custom_components`. 내부에`custom_components`폴더는 직접 위치해야 합니다`smart_plug_multilevel_light`.

카드는 통합에 포함되어 있으므로 카드를 설치하는 데 HACS가 필요하지 않습니다. 파일을 수동으로 복사하고, 홈어시스턴트를 다시 시작하고, 첫 번째 도우미 객체를 생성한 후 통합은 JavaScript 카드 파일을 게시하고 표준 모드의 패널 리소스에 자동으로 등록합니다.`storage`. YAML 리소스 모드에서는 아래 설명에 따라 카드를 수동으로 등록해야 합니다.

<a id="getting-started"></a>

## 🚀 설치 후 빠른 시작

### 🛠 구성

1. 열려 있&#xB294;**[설정 → 기기 및 서비스 → 액세서리](https://my.home-assistant.io/redirect/helpers/)**&#xADF8;리고 누르세요**도우미 개체 만들기**.

2. 선택하다**스마트 플러그 다단계 조명**.

3. 램프가 연결된 스마트 플러그를 선택하세요. 목록에는 홈어시스턴트가 동일한 장치에서 전원 센서를 확인하는 콘센트만 표시됩니다.

4. 다음 단계에서는 램프 매개변수를 설정합니다.
   * **조명 이름 (Light name)**— 생성되는 엔터티의 이름(예:`FloorLamp`;
   * **Power sensor**- 소켓 파워 센서;

5. 섹션에서**ZUI003Z**클릭하여 하나 이상의 밝기 모드를 추가하세요.**추가하다**.<br /> <img src="https://raw.githubusercontent.com/LanKing/ha-smart-plug-multilevel-light/main/docs/modes-edit.png" width="465"/><br /><br />
물리적 버튼으로 램프를 전환하고 모드 이름을 입력한 후 시작하세요.**Test stable power**. 안정된 값을 얻은 후**적용하다**.

6. 첫 번째 모드를 추가한 후 이 단계를 반복하여 나머지 모드를 추가합니다. 다음과 같이 끝나야 합니다.<br />
   <img src="https://raw.githubusercontent.com/LanKing/ha-smart-plug-multilevel-light/main/docs/modes-list.png" width="457"/><br />


7. 도우미 개체를 저장합니다. 홈어시스턴트가 새로운 엔터티를 생성합니다`light`, 예를 들어`light.FloorLamp`.

### 🧩 러브레이스 카드

1. 원하는 패널을 열고 편집 모드를 켜고**카드 추가**.
2. 선택하다**스마트 플러그 다단계 조명**, 생성된 엔터티를 지정합니다.`light`그리고 카드를 저장하세요.

사용 가능한 카드가 아닌 경우 다음을 사용 중일 수 있습니다.[Lovelace 리소스 YAML 모드](#yaml-lovelace-mode).

### 🎨 시각 효과

#### 카드 내 설정

카드가 있는 패널을 열고 편집 모드로 이동하여**편집하다**원하는 카드에

섹션 열기**콘텐츠 (Content)**, 사용 가능한 설정이 표시됩니다.

* **모드 이름 표시 (Show mode name)**— 현재 모드의 이름(예: 희미함, 낮음, 중간 또는 높음)을 표시하거나 숨깁니다.
* **백분율 표시 (Show percentage)**— 계산된 밝기를 백분율로 표시하거나 숨깁니다.

섹션 열기**상호 작용 (Interactions)**, 다음 내용이 표시됩니다.

* **아이콘 배경 항상 표시 (Always show icon background)**— 별도의 작업이 비활성화된 경우에도 아이콘 주변의 둥근 배경을 유지합니다.

> 🚫 그런데 저처럼 비표준 카드 아이콘을 사용하고 꺼졌을 때 시각적으로 줄이 그어져 있지 않다면 다른 플러그인을 추천합니다.[Mdi 꺼짐 폴백](https://github.com/LanKing/ha-mdi-off-fallback/blob/main/docs/README_ko.md), 이 미학적 문제를 해결합니다.

#### 밝기는 5%로 반올림됩니다.

열려 있&#xB294;**[설정 → 기기 및 서비스 → 액세서리](https://my.home-assistant.io/redirect/helpers/)**, 이전에 생성된 도우미 개체를 찾습니다.**스마트 플러그 다단계 조명**설정을 엽니다. 켜거나 끄기**Round brightness to 5% (may look nicer)**.

설정이 활성화되면 계산된 백분율은 가장 가까운 5%로 반올림됩니다(예: 33% → 35%, 67% → 65%).

반올림은 카드의 표시된 비율과 시각적 강도에만 영향을 미칩니다. 모드 정의 및 램프 작동은 변경되지 않습니다. 기본적으로 반올림은 비활성화되어 있습니다.

## 🧩 러브레이스 카드 자세히 보기

사용 가능한 옵션:

| 매개변수 | 유형 | 기본값 | 설명 |
|---|---|---:|---|
| `entity` | string | 필수 | 통합으로 생성된 엔터티 |
| `name` | string | 엔터티 이름 | 카드에 표시된 이름보다 우선 적용됩니다. |
| `icon` | string | 엔터티 아이콘 | 아이콘을 재정의합니다 |
| `show_mode` | boolean | `true` | 모드 이름을 보여줍니다 |
| `show_percentage` | boolean | `true` | 합성 비율을 보여줍니다 |
| `icon_tap_action` | action | `more-info` | 아이콘을 탭하면 추가 동작 |
| `always_show_icon_background` | boolean | `false` | icon_tap_action에 대해 None가 선택된 경우에도 항상 원형 아이콘 배경을 표시합니다. |

전체 예:

```yaml
type: custom:smart-plug-multilevel-light-card
entity: light.floor_lamp
name: Торшер
icon: mdi:floor-lamp
show_mode: true
show_percentage: true
icon_tap_action:
  action: more-info
always_show_icon_background: false
```

<a id="yaml-lovelace-mode"></a>

### Lovelace 리소스 YAML 모드

> 아마도 이 모드가 활성화되어 있지 않을 것입니다. 문제가 없고 카드가 작동하는 경우 이 단계를 건너뜁니다.

만약 당신이`configuration.yaml`명시적으로 설정됨:

```yaml
lovelace:
  resource_mode: yaml
```

홈어시스턴트는 통합이 리소스 목록을 자동으로 변경하는 것을 허용하지 않습니다. 이 경우 리소스를 수동으로 추가하세요.

```yaml
lovelace:
  resource_mode: yaml
  resources:
    - url: /api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
      type: module
```

변경 후 Lovelace 리소스를 재부팅하거나 홈어시스턴트를 다시 시작하세요.

## 🧯 문제 해결

<details>
<summary><b>❓통합이 도우미 목록에 표시되지 않습니다.</b></summary>
<br />

**예상 원인:**&#xACBD;로가 잘못되었거나 홈어시스턴트가 다시 시작되지 않았습니다.

파일 가용성을 확인하십시오.

```text
/config/custom_components/smart_plug_multilevel_light/manifest.json
```

그런 다음 홈어시스턴트를 완전히 다시 시작하고 로그에서 오류를 확인하세요.`smart_plug_multilevel_light`.

<hr />
</details>

<details>
<summary><b>❓플러그 목록이 비어 있습니다.</b></summary>
<br />

통합에는 개체만 표시됩니다.`switch`포함된 센서도 제공하는 장치와 관련됨`device_class: power`.

체크&#xC778;**[설정 → 장치 및 서비스 → 개체](https://my.home-assistant.io/redirect/entities/)**:

* 그들이 속해 있나요?`switch`하나의 장치에 대한 전력 센서가 있습니까?
* 파워센서가 켜져 있나요?
* 올바르게 지정되어 있습니까?`device_class`?
* 숫자 상태가 있나요?

<hr />
</details>

<details>
<summary><b>❓누락된 전원 센서 메시지와 함께 생성이 중지됩니다.</b></summary>
<br />

콘센트를 선택한 후 통합에서는 전원 센서가 있는지 다시 확인합니다. 센서가 제거되었거나, 비활성화되었거나, 다른 장치로 이동되었거나, 더 이상 센서가 작동하지 않는 경우 오류가 발생합니다.`device_class: power`.

<hr />
</details>

<details>
<summary><b>❓플러그가 켜져 있으면 램프가 꺼진 상태로 표시됩니다.</b></summary>
<br />

파워센서 값을 확인해보세요. 가상 램프는 다음과 같은 경우 꺼진 것으로 간주됩니다.`0 W`; 긍정적인 경우 다음과 같이 정의되어야 합니다.`on`.

<hr />
</details>

<details>
<summary><b>❓램프는 물리적으로 꺼져 있지만 켜짐으로 표시됩니다.</b></summary>
<br />

선택한 파워 센서가 실제로 표시되는지 확인하세요.`0 W`, 자체 버튼으로 램프가 꺼질 때.

<hr />
</details>

<details>
<summary><b>❓잘못된 모드가 감지되었습니다.</b></summary>
<br />

확인하다**🐞 Last measures**설정 및 속성에서`power_history`,`power_history_modes`,`power_sample_interval_seconds`그리고`selected_power_mode`.`power_history`마지막으로 기록된 전력 값을 표시합니다.`power_history_modes`— 구성된 임계값에 따른 각각의 모드,`power_sample_interval_seconds`주기적인 고정 간격이고,`selected_power_mode`— 현재 확인된 모드.

<hr />
</details>

<details>
<summary><b>❓모드 변경 사항이 즉시 표시되지 않습니다.</b></summary>
<br />

이는 예상된 동작입니다. 단기적인 전력 변동으로 인해 잘못된 스위칭이 발생하는 것을 방지하기 위해 통합은 여러 번의 연속 판독이 동일한 새 모드에 해당하는 후에만 모드를 변경합니다.

필요한 판독 횟수는 매개변수에 의해 설정됩니다.**Consecutive readings to switch**기본값은`5`. 주기적 측정은 초당 한 번씩 수행되며 센서 상태의 변화는 즉시 처리됩니다. 테스트 중에 값이 다른 모드에 해당하면 카운트다운이 다시 시작됩니다.

확인 전까지 통합은 이전 모드를 유지합니다. 덕분에 램프를 전환할 때 발생하는 중간 값, 전원 안정화 또는 센서 판독값의 작은 변동으로 인해 카드가 모드 간에 전환되지 않습니다.

판독값 수를 줄이면 새 모드 표시 속도가 빨라지지만 감지가 전력 변동에 더욱 민감해집니다.

<hr />
</details>

<details>
<summary><b>❓카드가 목록에 나타나지 않습니다</b></summary>
<br />

자동 등록은 구성된 도우미 개체를 하나 이상 로드한 후에만 발생하며 리소스 모드에서만 발생합니다.`storage`. HACS를 통해 또는 수동으로 통합을 설치하는 방법은 이에 영향을 미치지 않습니다.

확인하&#xB2E4;**[설정 → 패널 → ⋮ → 리소스](https://my.home-assistant.io/redirect/lovelace_resources/)**. URL은 다음 위치에 있어야 합니다.

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

YAML 모드에서[수동으로 리소스 추가](#yaml-lovelace-mode).

<hr />
</details>

<details>
<summary><b>❓업데이트 후에도 기존 카드가 계속 표시됩니다.</b></summary>
<br />

1. 홈어시스턴트를 완전히 다시 시작하세요.
2. 브라우저 캐시를 지우려면 페이지를 새로 고치세요.
3. 패널 리소스 URL에서 버전 번호를 확인하세요.
4. 모바일 애플리케이션에서 인터페이스를 완전히 닫았다가 다시 엽니다.

</details>
