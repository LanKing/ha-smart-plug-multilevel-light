> 该集成将非数字控制灯具和智能插头整合到一个家庭助理实体中。它根據功耗確定狀態和當前亮度模式，將它們顯示在卡中，並允許您透過短暫關閉並透過插座重新接通電源來開啟由其自己的按鈕關閉的燈。

# 🔌 智慧插頭多層燈

![Пример режимов на карточке](ha-smart-plug-multilevel-light-card-modes-v4.png)

**✨ 特色及特色：**

* 建立本機 Home Assistant 實體`light`與自動化、腳本和標準 HA 介面相容；
* 無論燈是如何關閉的，都能正確打開燈：如果透過智慧插座關閉電源，則只需將其打開；如果在插座打開時用自己的按鈕關閉燈，則會執行斷電和再次打開的循環；
* 根據實測穩定功率自動判斷燈具目前工作模式；
* 它有一個簡單的配置器，使用者可以在其中按順序命名其燈支援的模式，系統透過確定每種模式下的穩定功率來學習；
* 首次設定時，即時讀取電量：使用者只需將燈切換到下一個模式並按下學習按鈕即可；
* 成功過濾掉不穩定的功率讀數，防止功率在一種模式下「跳躍」時（甚至與下一種模式重合）時卡上指示燈出現混亂變化；
* 支援任意數量的模式；
* 該卡建立在標準家庭助理磁貼卡之上，保留其幾何形狀、背景、懸停效果、尺寸、排版和標準操作；
* 在卡片中，當前亮度透過顏色強度進行視覺編碼；
* 相對於最大功率線性計算亮度；可以將計算出的亮度四捨五入到 5%，以便更準確地顯示百分比；
* 允許您靈活定制卡片的顯示參數和外觀；
* 允許您僅選擇與所選智慧插頭相關的功率感測器；
* 讓您調整斷電週期的延遲，以正確操作不同型號的燈具和插座；
* 允許您設定功率閾值，低於該閾值燈將被視為關閉；
* 此介面針對 64 個 Home Assistant 區域設定進行了本地化。

## 🗜 準備鐵

您將需要：

1. 智慧插座，應向 HA 提供電源控制（開關）和電源測量（具有 device\_class：電源的傳感器）。兩個實體必須屬於同一設備並且已啟用。
2. 一種傻乎乎的燈，一旦插入電源就會自動打開，並具有多種亮度設置，讓您盡享享受。

> 我用了一個插座[塗鴉 TS011F（Girier 箱）](https://www.zigbee2mqtt.io/devices/TS011F_plug_3.html)。我要說的是，在實驗開始時，由於測量不準確，Girier系列插座不適合，但這個模型適合，儘管它也在Girier案例中。

### 👨‍🔬 我應用於我的插座的重要設定：

> 我的套接字不會自動向 HA 報告讀數，並且只允許按指定的時間間隔進行輪詢。預設為 60 秒。有必要將此間隔設為1秒，否則您將等待很長時間才能出現模式切換顯示。

此描述僅與透過 Z2M 連接的套接字的擁有者相關。其他使用者應在其配置中調整刷新率：

1. 打開**家庭助理 → Zigbee2MQTT**。如果 Zigbee2MQTT 不在侧面菜单中，请打开**設定 → 應用程式 → Zigbee2MQTT → 開啟 Web 介面**.
2. 轉到部分**裝置**.
3. 選擇所需的插座。
4. 打開選項卡**設定（具體）**.
5. 變化**測量輪詢間隔**1 秒。

## 🚀 安裝後快速啟動

### 🛠 配置

1. 打&#x958B;**[設定 → 設備和服務 → 配件](https://my.home-assistant.io/redirect/helpers/)**&#x4E26;按**建立輔助對象**.

2. 選擇**智慧插頭多層燈**.

3. 選擇燈所連接的智慧插頭。此清單僅顯示 Home Assistant 在同一裝置中看到功率感測器的插座。

4. 在下一步中，設定燈參數：
   * **燈光名稱 (Light name)**— 例如，正在建立的實體的名稱`FloorLamp`;
   * **Power sensor**- 插座功率感測器；

5. 在本節中**ZUI003Z**點選新增至少一種亮度模式**添加**.<br /> <img src="modes-edit.png" width="50%"/><br />用實體按鈕開關燈，輸入模式名稱並啟動**Test stable power**。獲得穩定值後，按**申請**.

6. 新增第一個模式後，重複這些步驟以新增其餘模式。你最終應該得到類似的結果：<br />
   <img src="modes-list.png" width="50%"/>

7. 保存輔助對象。 Home Assistant 將建立一個新實體`light`， 例如`light.FloorLamp`.

### 🧩 洛芙萊斯卡

1. 開啟所需的面板，開啟編輯模式並點擊**添加卡**.
2. 選擇**智慧插頭多層燈**,指定已建立的實體`light`並保存該卡。

如果該卡不在可用卡中，您可能正在使用[Lovelace資源YAML模式](#yaml-lovelace-mode).

### 🎨 視覺效果

#### 卡內設定

開啟卡片所在面板，進入編輯模式，點選**編輯**位於所需的卡片上。

打開該部分**內容 (Content)**，您將看到可用的設定：

* **顯示模式名稱 (Show mode name)**— 顯示或隱藏目前模式的名稱：例如，暗淡、低、中或高。
* **顯示百分比 (Show percentage)**— 以百分比形式顯示或隱藏計算出的亮度。

打開該部分**互動 (Interactions)**，你會看到：

* **一律顯示圖示背景 (Always show icon background)**— 保留圖示周圍的圓形背景，即使停用了單獨的操作。

> 🚫 順便說一句，如果您像我一樣使用非標準卡片圖標，並且關閉時它不會在視覺上被劃掉，我推薦我的另一個插件 -[Mdi 關閉後備](https://github.com/LanKing/ha-mdi-off-fallback/blob/main/docs/README_zh-Hant.md)，這就解決了這個美學問題。

#### 亮度四捨五入至 5%

打&#x958B;**[設定 → 設備和服務 → 配件](https://my.home-assistant.io/redirect/helpers/)**，找到先前建立的輔助對象**智慧插頭多層燈**並打開其設定。打開或關閉**Round brightness to 5% (may look nicer)**.

啟用設定後，計算出的百分比將四捨五入到最接近的 5%，例如：33% → 35%、67% → 65%。

四捨五入僅影響卡片的顯示百分比和視覺強度。燈的模式定義和操作不會改變。預設情況下，舍入是禁用的。

## 🧩 Lovelace 卡詳細信息

可用選項：

| 參數 | 類型 | 預設 | 描述 |
|---|---|---:|---|
| `entity` | string | 必填 | 整合創建的實體 |
| `name` | string | 實體名稱 | 覆蓋卡上顯示的姓名 |
| `icon` | string | 實體圖示 | 覆蓋圖示 |
| `show_mode` | boolean | `true` | 顯示模式名稱 |
| `show_percentage` | boolean | `true` | 顯示合成百分比 |
| `icon_tap_action` | action | `more-info` | 點選圖示時的附加操作 |
| `always_show_icon_background` | boolean | `false` | 始終顯示圓形圖示背景，即使為 icon_tap_action 選擇 None 也是如此 |

完整範例：

```yaml
type: custom:smart-plug-multilevel-light-card
entity: light.floor_lamp
name: Торшер
icon: mdi:floor-lamp
show_mode: true
show_percentage: true
icon_tap_action:
  action: more-info
always_show_icon_background: false
```

### Lovelace資源YAML模式

> 最有可能的是，您沒有啟用此模式。如果沒有問題且卡片工作正常，請跳過此步驟。

如果你有`configuration.yaml`明確設定：

```yaml
lovelace:
  resource_mode: yaml
```

Home Assistant 不允許整合自動變更資源清單。在這種情況下，請手動新增資源：

```yaml
lovelace:
  resource_mode: yaml
  resources:
    - url: /api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
      type: module
```

更改後，重新啟動 Lovelace 資源或重新啟動 Home Assistant。

<a id="troubleshooting"></a>

## 🧯 故障排除

<details>
<summary><b>❓整合未出現在幫助程式清單中</b></summary>
<br />

**可能的原因：**&#x8DEF;徑不正確或 Home Assistant 未重新啟動。

檢查文件可用性：

```text
/config/custom_components/smart_plug_multilevel_light/manifest.json
```

然後完全重新啟動 Home Assistant 並檢查日誌中是否有錯誤`smart_plug_multilevel_light`.

<hr />
</details>

<details>
<summary><b>❓插頭列表為空</b></summary>
<br />

整合僅顯示對象`switch`與也提供附帶感測器的設備相關聯`device_class: power`.

報&#x5230;**[設定 → 設備和服務 → 對象](https://my.home-assistant.io/redirect/entities/)**:

* 他們屬於嗎`switch`和一台設備的功率感測器？
* 功率感測器是否開啟？
* 指定是否正確？`device_class`?
* 它有數字狀態嗎？

<hr />
</details>

<details>
<summary><b>❓創建因缺少功率感測器訊息而停止</b></summary>
<br />

選擇插座後，整合會重新檢查是否有功率感測器。如果感測器已被移除、停用、移至其他裝置或不再具有，則會發生錯誤`device_class: power`.

<hr />
</details>

<details>
<summary><b>❓插頭開啟時燈顯示為關閉</b></summary>
<br />

檢查功率感測器值。虛擬燈被認為關閉時`0 W`;當為正時，應定義為`on`.

<hr />
</details>

<details>
<summary><b>❓燈在物理關閉時顯示為打開</b></summary>
<br />

檢查所選功率感測器是否實際顯示`0 W`，當燈通過其自身的按鈕關閉時。

<hr />
</details>

<details>
<summary><b>❓偵測到錯誤模式</b></summary>
<br />

查看**🐞 Last measures**在設定和屬性中`power_history`,`power_history_modes`,`power_sample_interval_seconds`和`selected_power_mode`.`power_history`顯示最後記錄的功率值，`power_history_modes`— 根據配置的閾值每個人的模式，`power_sample_interval_seconds`是周期性注視的間隔，並且`selected_power_mode`— 目前確認模式。

<hr />
</details>

<details>
<summary><b>❓模式變更不會立即顯示</b></summary>
<br />

這是預期的行為。为了防止短期功率波动引起杂散切换，积分仅在多个连续读数对应于相同的新模式后才改变模式。

所需的讀數數量由參數設定**Consecutive readings to switch**並預設為`5`。每秒执行一次定期测量，并立即处理传感器状态的变化。如果在测试期间该值对应于不同的模式，则倒计时再次开始。

在確認之前，集成保持之前的模式。因此，该卡不会因切换灯时出现的中间值、稳定其功率或传感器读数的小波动而在模式之间切换。

減少讀數的數量加快了新模式的顯示速度，但使偵測對功率波動更加敏感。

<hr />
</details>

<details>
<summary><b>❓該卡未出現在清單中</b></summary>
<br />

僅在載入至少一個已配置的輔助物件後且僅在資源模式下才會發生自動註冊`storage`。安装集成的方法（通过 HACS 或手动）不会影响这一点。

查&#x770B;**[設定 → 面板 → ⋮ → 資源](https://my.home-assistant.io/redirect/lovelace_resources/)**。 URL 應該在那裡：

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

在 YAML 模式下[手動新增資源](#yaml-lovelace-mode).

<hr />
</details>

<details>
<summary><b>❓更新後仍顯示舊卡</b></summary>
<br />

1. 完全重新啟動家庭助理。
2. 重新整理頁面以清除瀏覽器快取。
3. 檢查面板資源 URL 中的版本號。
4. 在行動應用程式中，完全關閉並重新打開介面。

<hr />
</details>

## 🗑 移除

1. 刪除所有已建立的輔助對象**智慧插頭多層燈**透&#x904E;**[設定 → 設備和服務 → 配件](https://my.home-assistant.io/redirect/helpers/)**.
2. 透過 HACS 刪除整合或手動刪除資料夾：

```text
/config/custom_components/smart_plug_multilevel_light
```

3. 查&#x770B;**[設定 → 面板 → ⋮ → 資源](https://my.home-assistant.io/redirect/lovelace_resources/)**&#x5982;果還有的話，手動刪除卡片資源：

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

4. 完全重新啟動家庭助理。
5. 如有必要，請刷新頁面以清除介面快取。
