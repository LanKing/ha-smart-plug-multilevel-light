# 🔌 ஸ்மார்ட் பிளக் மல்டி-லெவல் லைட்

* சொந்த வீட்டு உதவியாளர் நிறுவனத்தை உருவாக்குகிறது`light`ஆட்டோமேஷன்கள், ஸ்கிரிப்டுகள் மற்றும் நிலையான HA இடைமுகத்துடன் இணக்கமானது;

* உண்மையில் அளவிடப்பட்ட நிலையான சக்தியின் அடிப்படையில் விளக்கின் தற்போதைய இயக்க முறைமையை தானாகவே தீர்மானிக்கிறது;
* இது ஒரு எளிய கட்டமைப்பாளரைக் கொண்டுள்ளது, அதில் பயனர் தனது விளக்கால் ஆதரிக்கப்படும் முறைகளுக்கு வரிசையாக பெயரிடுகிறார், மேலும் ஒவ்வொரு பயன்முறையிலும் நிலையான சக்தியைத் தீர்மானிப்பதன் மூலம் கணினி கற்றுக்கொள்கிறது;

* நிலையற்ற சக்தி அளவீடுகளை வெற்றிகரமாக வடிகட்டுகிறது, சக்தி ஒரு பயன்முறையில் "குதிக்கும்" போது கார்டில் உள்ள குறிகாட்டியின் குழப்பமான மாற்றங்களைத் தடுக்கிறது (மற்றும் அடுத்த பயன்முறையுடன் கூட ஒத்துப்போகிறது);

* கார்டு நிலையான ஹோம் அசிஸ்டண்ட் டைல் கார்டின் மேல் கட்டப்பட்டுள்ளது, அதன் வடிவவியல், பின்னணி, மிதவை விளைவுகள், அளவுகள், அச்சுக்கலை மற்றும் நிலையான செயல்களைப் பாதுகாக்கிறது;
* அட்டையில், தற்போதைய பிரகாசம் வண்ண தீவிரத்தால் பார்வைக்கு குறியாக்கம் செய்யப்படுகிறது;
* அதிகபட்ச சக்தியுடன் ஒப்பிடும்போது பிரகாசத்தை நேர்கோட்டில் கணக்கிடுகிறது; கணக்கிடப்பட்ட பிரகாசத்தை 5% க்கு ரவுண்டிங் செய்வது, சதவீதங்களின் துல்லியமான காட்சிக்கு இயக்கப்படலாம்;
* காட்டப்படும் அளவுருக்கள் மற்றும் அட்டையின் தோற்றத்தை நெகிழ்வாகத் தனிப்பயனாக்க உங்களை அனுமதிக்கிறது;
* தேர்ந்தெடுக்கப்பட்ட ஸ்மார்ட் பிளக் தொடர்பான பவர் சென்சார் மட்டும் தேர்ந்தெடுக்க உங்களை அனுமதிக்கிறது;
* விளக்குகள் மற்றும் சாக்கெட்டுகளின் வெவ்வேறு மாதிரிகள் மூலம் சரியான செயல்பாட்டிற்காக டி-ஆற்றல் சுழற்சியின் தாமதத்தை சரிசெய்ய உங்களை அனுமதிக்கிறது;
* விளக்கு அணைக்கப்பட்டதாகக் கருதப்படும் சக்தி வாசலை அமைக்க உங்களை அனுமதிக்கிறது;
* 64 ஹோம் அசிஸ்டண்ட் லோகேல்களுக்கு இடைமுகம் மொழிபெயர்க்கப்பட்டுள்ளது.

## 🗜 இரும்பு தயார்

உங்களுக்கு இது தேவைப்படும்:

1. HAக்கு பவர் கண்ட்ரோல் (சுவிட்ச்) மற்றும் பவர் அளவீட்டை (சாதனம்\_கிளாஸ் கொண்ட சென்சார்: பவர்) வழங்கும் ஸ்மார்ட் சாக்கெட். இரண்டு நிறுவனங்களும் ஒரே சாதனத்தைச் சேர்ந்தவை மற்றும் இயக்கப்பட்டிருக்க வேண்டும்.
2. ஒரு முறை ப்ளக்-இன் செய்தவுடன் தானாகவே இயங்கும் மற்றும் முழுமையான இன்பத்திற்கான பல பிரகாச அமைப்புகளைக் கொண்ட ஒரு வேடிக்கையான ஒளி.

> நான் ஒரு சாக்கெட்டைப் பயன்படுத்தினேன்[Tuya TS011F (கிரியர் வழக்கில்)](https://www.zigbee2mqtt.io/devices/TS011F_plug_3.html). சோதனைகளின் தொடக்கத்தில், கிரியர் தொடர் சாக்கெட்டுகள் துல்லியமற்ற அளவீடுகளால் பொருந்தவில்லை என்று நான் கூறுவேன், ஆனால் இந்த மாதிரியானது கிரியர் வழக்கிலும் இருந்தது.

### 👨‍🔬 எனது அவுட்லெட்டில் நான் பயன்படுத்திய முக்கியமான அமைப்பு:

> எனது சாக்கெட் தானாக அளவீடுகளை HAக்கு தெரிவிக்காது மற்றும் குறிப்பிட்ட இடைவெளியில் மட்டுமே வாக்கெடுப்பை அனுமதிக்கிறது. இயல்பாக இது 60 வினாடிகள். இந்த இடைவெளியை 1 வினாடிக்கு அமைக்க வேண்டியது அவசியம், இல்லையெனில் பயன்முறை மாறுதல் காட்சி தோன்றுவதற்கு நீங்கள் மிக நீண்ட நேரம் காத்திருக்க வேண்டும்.

Z2M வழியாக இணைக்கப்பட்ட சாக்கெட்டுகளின் உரிமையாளர்களுக்கு மட்டுமே இந்த விளக்கம் பொருத்தமானது. பிற பயனர்கள் புதுப்பிப்பு விகிதத்தை தங்கள் உள்ளமைவுக்குள் சரிசெய்ய வேண்டும்:

1. திற**வீட்டு உதவியாளர் → Zigbee2MQTT**. Zigbee2MQTT பக்க மெனுவில் இல்லை என்றால், திறக்கவும்**அமைப்புகள் → பயன்பாடுகள் → Zigbee2MQTT → இணைய இடைமுகத்தைத் திற**.
2. பகுதிக்குச் செல்லவும்**சாதனங்கள்**.
3. தேவையான கடையைத் தேர்ந்தெடுக்கவும்.
4. தாவலைத் திறக்கவும்**அமைப்புகள் (குறிப்பிட்டவை)**.
5. மாற்றங்கள்**அளவீட்டு வாக்கெடுப்பு இடைவெளி**அன்று 1 வி.

#### 1. களஞ்சியத்தைச் சேர்த்தல்

2. மேல் வலது மூலையில் உள்ள மெனுவைத் திறந்து தேர்ந்தெடுக்கவும்**தனிப்பயன் களஞ்சியங்கள்**.
3. சேர்:

```text
https://github.com/LanKing/ha-smart-plug-multilevel-light
```

4. வகையைத் தேர்ந்தெடுக்கவும்**ஒருங்கிணைப்பு**மற்றும் அழுத்தவும்**சேர்**.

2. ஒருங்கிணைப்பைத் திறந்து கிளிக் செய்யவும்**பதிவிறக்கவும்**.

### 🧑‍💻 HACS இல்லாமல் நிறுவல்

1. களஞ்சியப் பக்கத்தில், கிளிக் செய்யவும்**குறியீடு → ஜிப் பதிவிறக்கவும்**.
2. காப்பகத்தைத் திறக்கவும்.
3. கோப்புறையை நகலெடுக்கவும்:

```text
custom_components/smart_plug_multilevel_light
```

வீட்டு உதவியாளர் உள்ளமைவு கோப்பகத்திற்கு:

```text
/config/custom_components/smart_plug_multilevel_light
```

இறுதி கோப்பு பாதை`manifest.json`இப்படி இருக்க வேண்டும்:

```text
/config/custom_components/smart_plug_multilevel_light/manifest.json
```

4. வீட்டு உதவியாளரை முழுமையாக மறுதொடக்கம் செய்யுங்கள்.

> முழு வெளிப்புற களஞ்சிய கோப்புறையையும் நகலெடுக்க வேண்டாம்`custom_components`. உள்ளே`custom_components`கோப்புறை நேரடியாக அமைந்திருக்க வேண்டும்`smart_plug_multilevel_light`.

கார்டு ஒருங்கிணைப்பில் சேர்க்கப்பட்டுள்ளது, எனவே அதை நிறுவ HACS தேவையில்லை. கோப்புகளை கைமுறையாக நகலெடுத்து, முகப்பு உதவியாளரை மறுதொடக்கம் செய்து, முதல் உதவிப் பொருளை உருவாக்கிய பிறகு, ஒருங்கிணைப்பு ஜாவாஸ்கிரிப்ட் கார்டு கோப்பை வெளியிடுகிறது மற்றும் நிலையான பயன்முறையில் பேனல் ஆதாரங்களுடன் தானாகவே பதிவு செய்கிறது`storage`. YAML ஆதார பயன்முறையில், கீழே விவரிக்கப்பட்டுள்ளபடி, அட்டை கைமுறையாகப் பதிவு செய்யப்பட வேண்டும்.

## 🚀 நிறுவிய பின் விரைவான தொடக்கம்

### 🛠 கட்டமைப்பு

1. தி&#xBB1;**[அமைப்புகள் → சாதனங்கள் மற்றும் சேவைகள் → பாகங்கள்](https://my.home-assistant.io/redirect/helpers/)**&#xBAE;ற்றும் அழுத்தவும்**உதவி பொருளை உருவாக்கவும்**.

2. தேர்ந்தெடு**ஸ்மார்ட் பிளக் மல்டி-லெவல் லைட்**.

3. விளக்கு இணைக்கப்பட்டுள்ள ஸ்மார்ட் பிளக்கைத் தேர்ந்தெடுக்கவும். ஹோம் அசிஸ்டண்ட் ஒரே சாதனத்தில் பவர் சென்சார் பார்க்கும் கடைகளை மட்டுமே பட்டியல் காட்டுகிறது.

4. அடுத்த கட்டத்தில், விளக்கு அளவுருக்களை அமைக்கவும்:
   * **விளக்கின் பெயர் (Light name)**- எடுத்துக்காட்டாக, உருவாக்கப்படும் நிறுவனத்தின் பெயர்`FloorLamp`;
   * **Power sensor**- சாக்கெட் பவர் சென்சார்;

5. பிரிவில்**ZUI003Z**கிளிக் செய்வதன் மூலம் குறைந்தது ஒரு பிரகாச பயன்முறையைச் சேர்க்கவும்**சேர்**.<br /> <img src="https://raw.githubusercontent.com/LanKing/ha-smart-plug-multilevel-light/main/docs/modes-edit.png" width="465"/><br /><br />
விளக்கை அதன் இயற்பியல் பொத்தானைக் கொண்டு மாற்றவும், பயன்முறையின் பெயரை உள்ளிட்டு தொடங்கவும்**Test stable power**. நிலையான மதிப்பைப் பெற்ற பிறகு, அழுத்தவும்**விண்ணப்பிக்கவும்**.

6. முதல் பயன்முறையைச் சேர்த்த பிறகு, இந்த படிகளை மீண்டும் செய்வதன் மூலம் மீதமுள்ள முறைகளைச் சேர்க்கவும். நீங்கள் இதைப் போன்ற ஒன்றை முடிக்க வேண்டும்:<br />
   <img src="https://raw.githubusercontent.com/LanKing/ha-smart-plug-multilevel-light/main/docs/modes-list.png" width="457"/><br />


7. உதவி பொருளை சேமிக்கவும். வீட்டு உதவியாளர் புதிய நிறுவனத்தை உருவாக்குவார்`light`, உதாரணமாக`light.FloorLamp`.

### 🧩 லவ்லேஸ் அட்டை

1. விரும்பிய பேனலைத் திறந்து, திருத்து பயன்முறையை இயக்கி கிளிக் செய்யவும்**ஒரு அட்டையைச் சேர்க்கவும்**.
2. தேர்ந்தெடு**ஸ்மார்ட் பிளக் மல்டி-லெவல் லைட்**, உருவாக்கப்பட்ட நிறுவனத்தைக் குறிப்பிடவும்`light`மற்றும் அட்டையை சேமிக்கவும்.

கிடைக்கக்கூடியவற்றில் கார்டு இல்லையென்றால், நீங்கள் பயன்படுத்தலாம்[லவ்லேஸ் வள YAML பயன்முறை](#yaml-lovelace-mode).

### 🎨 காட்சி விளைவுகள்

#### அட்டையில் உள்ள அமைப்புகள்

அட்டை அமைந்துள்ள பேனலைத் திறந்து, திருத்த பயன்முறைக்குச் சென்று கிளிக் செய்யவும்**திருத்தவும்**விரும்பிய அட்டையில்.

பிரிவைத் திறக்கிறது**உள்ளடக்கம் (Content)**, நீங்கள் கிடைக்கக்கூடிய அமைப்புகளைக் காண்பீர்கள்:

* **முறை பெயரை காட்டு (Show mode name)**— தற்போதைய பயன்முறையின் பெயரைக் காட்டுகிறது அல்லது மறைக்கிறது: எடுத்துக்காட்டாக, மங்கலான, குறைந்த, நடுத்தர அல்லது உயர்.
* **சதவீதத்தை காட்டு (Show percentage)**- கணக்கிடப்பட்ட பிரகாசத்தை சதவீதமாகக் காட்டுகிறது அல்லது மறைக்கிறது.

பிரிவைத் திறக்கிறது**தொடர்புகள் (Interactions)**, நீங்கள் பார்ப்பீர்கள்:

* **ஐகான் பின்னணியை எப்போதும் காட்டு (Always show icon background)**— ஐகானைச் சுற்றி ஒரு சுற்று பின்னணியை வைத்திருக்கிறது, அதற்கான தனிச் செயல் முடக்கப்பட்டிருந்தாலும் கூட.

> 🚫, என்னைப் போலவே, நீங்கள் தரமற்ற கார்டு ஐகானைப் பயன்படுத்தினால், அதை அணைக்கும்போது அது பார்வைக்கு குறுக்கிடப்படாமல் இருந்தால், எனது மற்ற செருகுநிரலைப் பரிந்துரைக்கிறேன் -[Mdi ஆஃப் ஃபால்பேக்](https://github.com/LanKing/ha-mdi-off-fallback/blob/main/docs/README_ta.md), இது இந்த அழகியல் சிக்கலை தீர்க்கிறது.

#### பிரகாசம் 5% வரை ரவுண்டிங்

தி&#xBB1;**[அமைப்புகள் → சாதனங்கள் மற்றும் சேவைகள் → பாகங்கள்](https://my.home-assistant.io/redirect/helpers/)**, முன்பு உருவாக்கப்பட்ட உதவி பொருளைக் கண்டறியவும்**ஸ்மார்ட் பிளக் மல்டி-லெவல் லைட்**மற்றும் அதன் அமைப்புகளைத் திறக்கவும். ஆன் அல்லது ஆஃப்**Round brightness to 5% (may look nicer)**.

அமைப்பு இயக்கப்பட்டால், கணக்கிடப்பட்ட சதவீதம் அருகிலுள்ள 5%க்கு வட்டமிடப்படும், எடுத்துக்காட்டாக: 33% → 35%, 67% → 65%.

ரவுண்டிங் காட்டப்படும் சதவீதம் மற்றும் கார்டின் காட்சி தீவிரத்தை மட்டுமே பாதிக்கும். விளக்கின் பயன்முறை வரையறை மற்றும் செயல்பாடு மாறாது. இயல்பாக, ரவுண்டிங் முடக்கப்பட்டுள்ளது.

## 🧩 லவ்லேஸ் அட்டை விவரம்

கிடைக்கக்கூடிய விருப்பங்கள்:

| அளவுரு | வகை | இயல்புநிலை | விளக்கம் |
|---|---|---:|---|
| `entity` | string | தேவை | ஒருங்கிணைப்பால் உருவாக்கப்பட்ட நிறுவனம் |
| `name` | string | நிறுவனத்தின் பெயர் | அட்டையில் காட்டப்பட்டுள்ள பெயரை மீறுகிறது |
| `icon` | string | நிறுவன ஐகான் | ஐகானை மீறுகிறது |
| `show_mode` | boolean | `true` | பயன்முறையின் பெயரைக் காட்டுகிறது |
| `show_percentage` | boolean | `true` | செயற்கை சதவீதத்தைக் காட்டுகிறது |
| `icon_tap_action` | action | `more-info` | ஐகானைத் தட்டும்போது கூடுதல் செயல் |
| `always_show_icon_background` | boolean | `false` | icon_tap_action க்கு None தேர்ந்தெடுக்கப்பட்டாலும், எப்போதும் வட்ட ஐகான் பின்னணியைக் காட்டுகிறது |

முழு உதாரணம்:

```yaml
type: custom:smart-plug-multilevel-light-card
entity: light.floor_lamp
name: Торшер
icon: mdi:floor-lamp
show_mode: true
show_percentage: true
icon_tap_action:
  action: more-info
always_show_icon_background: false
```

### லவ்லேஸ் வள YAML பயன்முறை

> பெரும்பாலும், உங்களிடம் இந்த பயன்முறை இயக்கப்படவில்லை. எந்த பிரச்சனையும் இல்லை மற்றும் அட்டை வேலை செய்தால், இந்த படிநிலையைத் தவிர்க்கவும்.

உங்களிடம் இருந்தால்`configuration.yaml`வெளிப்படையாக அமைக்கப்பட்டது:

```yaml
lovelace:
  resource_mode: yaml
```

ஹோம் அசிஸ்டண்ட், ஒருங்கிணைப்பை தானாகவே ஆதாரங்களின் பட்டியலை மாற்ற அனுமதிக்காது. இந்த வழக்கில், வளத்தை கைமுறையாகச் சேர்க்கவும்:

```yaml
lovelace:
  resource_mode: yaml
  resources:
    - url: /api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
      type: module
```

மாற்றத்திற்குப் பிறகு, Lovelace ஆதாரங்களை மீண்டும் துவக்கவும் அல்லது Home Assistantடை மறுதொடக்கம் செய்யவும்.

இது எதிர்பார்க்கப்படும் நடத்தை. குறுகிய கால மின் ஏற்ற இறக்கங்கள் போலியான மாறுதலை ஏற்படுத்துவதைத் தடுக்க, பல தொடர்ச்சியான அளவீடுகளுக்குப் பிறகுதான் ஒருங்கிணைப்பு பயன்முறையை மாற்றுகிறது.

தேவையான அளவீடுகளின் எண்ணிக்கை அளவுருவால் அமைக்கப்படுகிறது**Consecutive readings to switch**மற்றும் இயல்புநிலை`5`. கால அளவீடுகள் ஒரு வினாடிக்கு ஒரு முறை செய்யப்படுகின்றன, மேலும் சென்சார் நிலையில் ஏற்படும் மாற்றங்கள் உடனடியாக செயலாக்கப்படும். சோதனையின் போது மதிப்பு வேறு பயன்முறைக்கு ஒத்திருந்தால், கவுண்டவுன் மீண்டும் தொடங்குகிறது.

உறுதிப்படுத்தும் வரை, ஒருங்கிணைப்பு முந்தைய பயன்முறையைப் பராமரிக்கிறது. இதற்கு நன்றி, விளக்கை மாற்றும்போது, ​​​​அதன் சக்தியை உறுதிப்படுத்தும்போது அல்லது சென்சார் அளவீடுகளில் சிறிய ஏற்ற இறக்கங்கள் ஏற்படும் போது ஏற்படும் இடைநிலை மதிப்புகள் காரணமாக அட்டை முறைகளுக்கு இடையில் மாறாது.

வாசிப்புகளின் எண்ணிக்கையைக் குறைப்பது புதிய பயன்முறையின் காட்சியை விரைவுபடுத்துகிறது, ஆனால் சக்தி ஏற்ற இறக்கங்களுக்கு கண்டறிதலை அதிக உணர்திறன் கொண்டதாக ஆக்குகிறது.

சரிபார்க்கவும&#xBCD;**[அமைப்புகள் → பேனல்கள் → ⋮ → வளங்கள்](https://my.home-assistant.io/redirect/lovelace_resources/)**. URL இருக்க வேண்டும்:

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

YAML பயன்முறையில்[கைமுறையாக வளத்தைச் சேர்க்கவும்](#yaml-lovelace-mode).

## 🗑 அகற்றுதல்

1. உருவாக்கப்பட்ட அனைத்து உதவி பொருட்களையும் நீக்கவும்**ஸ்மார்ட் பிளக் மல்டி-லெவல் லைட்**மூலம&#xBCD;**[அமைப்புகள் → சாதனங்கள் மற்றும் சேவைகள் → பாகங்கள்](https://my.home-assistant.io/redirect/helpers/)**.
2. HACS வழியாக ஒருங்கிணைப்பை அகற்றவும் அல்லது கோப்புறையை கைமுறையாக நீக்கவும்:

```text
/config/custom_components/smart_plug_multilevel_light
```

3. சரிபார்க்கவும&#xBCD;**[அமைப்புகள் → பேனல்கள் → ⋮ → வளங்கள்](https://my.home-assistant.io/redirect/lovelace_resources/)**&#xB95;ார்டு ஆதாரம் இருந்தால் அதை கைமுறையாக நீக்கவும்:

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

4. வீட்டு உதவியாளரை முழுமையாக மறுதொடக்கம் செய்யுங்கள்.
5. தேவைப்பட்டால், இடைமுக தற்காலிக சேமிப்பை அழிக்க பக்கத்தைப் புதுப்பிக்கவும்.
