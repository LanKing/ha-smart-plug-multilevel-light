## 🗜 لوہا تیار کرنا

آپ کو ضرورت ہو گی:

1. ایک سمارٹ ساکٹ جو HA کو پاور کنٹرول (سوئچ) اور پاور پیمائش (ڈیوائس\_کلاس: پاور کے ساتھ سینسر) فراہم کرے۔ دونوں اداروں کا ایک ہی ڈیوائس سے تعلق ہونا چاہیے اور ان کا فعال ہونا چاہیے۔
2. ایک بے وقوف روشنی جو ایک بار پلگ ان ہونے کے بعد خود بخود آن ہو جاتی ہے اور مکمل لطف اندوز ہونے کے لیے چمک کی متعدد ترتیبات رکھتی ہے۔

> میں نے ایک ساکٹ استعمال کیا۔[Tuya TS011F (گیریئر کیس میں)](https://www.zigbee2mqtt.io/devices/TS011F_plug_3.html). میں یہ کہوں گا کہ تجربات کے آغاز میں، ساکٹ کی گیریئر سیریز غلط پیمائش کی وجہ سے فٹ نہیں ہوئی تھی، لیکن اس ماڈل نے ایسا کیا، حالانکہ یہ گیئر کیس میں بھی تھا۔

### 👨‍🔬 اہم ترتیب جو میں نے اپنے آؤٹ لیٹ پر لاگو کی تھی:

> میرا ساکٹ خود بخود HA کو ریڈنگ کی اطلاع نہیں دیتا ہے اور صرف ایک مخصوص وقفہ پر پولنگ کی اجازت دیتا ہے۔ پہلے سے طے شدہ طور پر یہ 60 سیکنڈ تھا۔ اس وقفہ کو 1 سیکنڈ پر سیٹ کرنا ضروری ہے، بصورت دیگر آپ موڈ سوئچنگ ڈسپلے کے ظاہر ہونے کے لیے کافی وقت انتظار کریں گے۔

یہ تفصیل صرف Z2M کے ذریعے منسلک ساکٹ کے مالکان کے لیے متعلقہ ہے۔ دوسرے صارفین کو اپنی ترتیب میں ریفریش کی شرح کو ایڈجسٹ کرنا چاہئے:

```text
custom_components/smart_plug_multilevel_light
```

ہوم اسسٹنٹ کنفیگریشن ڈائرکٹری میں:

```text
/config/custom_components/smart_plug_multilevel_light
```

فائل کا آخری راستہ`manifest.json`اس طرح نظر آنا چاہئے:

```text
/config/custom_components/smart_plug_multilevel_light/manifest.json
```

4. ہوم اسسٹنٹ کو مکمل طور پر دوبارہ شروع کریں۔

> پورے ایکسٹرنل ریپوزٹری فولڈر کو کاپی نہ کریں۔`custom_components`. اندر`custom_components`فولڈر براہ راست واقع ہونا ضروری ہے`smart_plug_multilevel_light`.

کارڈ انضمام میں شامل ہے، لہذا HACS کو اسے انسٹال کرنے کی ضرورت نہیں ہے۔ فائلوں کو دستی طور پر کاپی کرنے، ہوم اسسٹنٹ کو دوبارہ شروع کرنے، اور پہلا مددگار آبجیکٹ بنانے کے بعد، انضمام JavaScript کارڈ فائل کو شائع کرتا ہے اور اسے معیاری وضع میں پینل وسائل کے ساتھ خودکار طور پر رجسٹر کرتا ہے۔`storage`. YAML ریسورس موڈ میں، کارڈ کو دستی طور پر رجسٹر کیا جانا چاہیے، جیسا کہ ذیل میں بیان کیا گیا ہے۔

<a id="getting-started"></a>

## 🚀 تنصیب کے بعد فوری آغاز

### 🛠 کنفیگریشن

1. کھولیں۔**[ترتیبات → آلات اور خدمات → لوازمات](https://my.home-assistant.io/redirect/helpers/)**&#x627;ور دبائیں**مددگار آبجیکٹ بنائیں**.

2. منتخب کریں۔**اسمارٹ پلگ ملٹی لیول لائٹ**.

3. وہ سمارٹ پلگ منتخب کریں جس سے لیمپ منسلک ہے۔ فہرست صرف آؤٹ لیٹس کو دکھاتی ہے جہاں ہوم اسسٹنٹ اسی ڈیوائس میں پاور سینسر دیکھتا ہے۔

4. اگلے مرحلے میں، چراغ کے پیرامیٹرز مقرر کریں:
   * **لائٹ کا نام (Light name)**— تخلیق ہونے والی ہستی کا نام، مثال کے طور پر`FloorLamp`;
   * **Power sensor**- ساکٹ پاور سینسر؛

5. سیکشن میں**ZUI003Z**کلک کرکے کم از کم ایک چمک موڈ شامل کریں۔**شامل کریں۔**.<br /> <img src="modes-edit.png" width="50%"/><br />لیمپ کو اس کے فزیکل بٹن سے سوئچ کریں، موڈ کا نام درج کریں اور اسٹارٹ کریں۔**Test stable power**. ایک مستحکم قیمت حاصل کرنے کے بعد، دبائیں**لگائیں**.

6. پہلا موڈ شامل کرنے کے بعد، ان مراحل کو دہراتے ہوئے بقیہ موڈز کو شامل کریں۔ آپ کو کچھ اس طرح ختم کرنا چاہئے:<br />
   <img src="modes-list.png" width="50%"/>

7. مددگار آبجیکٹ کو محفوظ کریں۔ ہوم اسسٹنٹ ایک نیا ادارہ بنائے گا۔`light`، مثال کے طور پر`light.FloorLamp`.

### 🧩 لولیس کارڈ

1. مطلوبہ پینل کھولیں، ترمیم موڈ کو آن کریں اور کلک کریں۔**ایک کارڈ شامل کریں۔**.
2. منتخب کریں۔**اسمارٹ پلگ ملٹی لیول لائٹ**، تخلیق کردہ ہستی کی وضاحت کریں۔`light`اور کارڈ کو محفوظ کریں.

اگر کارڈ دستیاب کارڈز میں سے نہیں ہے، تو ہو سکتا ہے آپ استعمال کر رہے ہوں۔[Lovelace وسائل YAML موڈ](#yaml-lovelace-mode).

### 🎨 بصری اثرات

#### کارڈ میں ترتیبات

وہ پینل کھولیں جہاں کارڈ موجود ہے، ایڈٹ موڈ پر جائیں اور کلک کریں۔**ترمیم کریں۔**&#x645;طلوبہ کارڈ پر۔

سیکشن کھولنا**مواد (Content)**، آپ دستیاب ترتیبات دیکھیں گے:

* **موڈ کا نام دکھائیں (Show mode name)**- موجودہ موڈ کا نام دکھاتا یا چھپاتا ہے: مثال کے طور پر، مدھم، کم، درمیانہ یا زیادہ۔
* **فیصد دکھائیں (Show percentage)**- حسابی چمک کو فیصد کے طور پر دکھاتا یا چھپاتا ہے۔

سیکشن کھولنا**تعاملات (Interactions)**، آپ دیکھیں گے:

* **آئیکن کا پس منظر ہمیشہ دکھائیں (Always show icon background)**- آئیکن کے ارد گرد گول پس منظر کو برقرار رکھتا ہے، یہاں تک کہ اگر اس کے لیے علیحدہ کارروائی غیر فعال ہو۔

> 🚫 ویسے، اگر آپ، میری طرح، ایک غیر معیاری کارڈ کا آئیکن استعمال کرتے ہیں اور جب اسے آف کر دیا جاتا ہے تو اسے بصری طور پر کراس نہیں کیا جاتا، میں اپنے دوسرے پلگ ان کی تجویز کرتا ہوں -[ایم ڈی آئی آف فال بیک](https://github.com/LanKing/ha-mdi-off-fallback/blob/main/docs/README_ur.md)، جو اس جمالیاتی مسئلہ کو حل کرتا ہے۔

#### چمک 5% تک بڑھ رہی ہے

کھولیں۔**[ترتیبات → آلات اور خدمات → لوازمات](https://my.home-assistant.io/redirect/helpers/)**، مددگار آبجیکٹ کو تلاش کریں جو پہلے بنایا گیا تھا۔**اسمارٹ پلگ ملٹی لیول لائٹ**اور اس کی ترتیبات کھولیں۔ آن یا آف کریں۔**Round brightness to 5% (may look nicer)**.

ترتیب کو فعال کرنے پر، حساب شدہ فیصد قریب ترین 5% پر گول کر دیا جاتا ہے، مثال کے طور پر: 33% → 35%، 67% → 65%۔

گول کرنا صرف کارڈ کے دکھائے گئے فیصد اور بصری شدت کو متاثر کرتا ہے۔ چراغ کے موڈ کی تعریف اور آپریشن تبدیل نہیں ہوتا ہے۔ بطور ڈیفالٹ، راؤنڈنگ غیر فعال ہے۔

## 🧩 لولیس کارڈ تفصیل سے

دستیاب اختیارات:

| پیرامیٹر | قسم | طے شدہ | تفصیل |
|---|---|---:|---|
| `entity` | string | کی ضرورت ہے | انضمام کے ذریعہ تخلیق کردہ ہستی |
| `name` | string | ہستی کا نام | کارڈ پر دکھائے گئے نام کو اوور رائیڈ کرتا ہے۔ |
| `icon` | string | ہستی کا آئیکن | آئیکن کو اوور رائیڈ کرتا ہے۔ |
| `show_mode` | boolean | `true` | موڈ کا نام دکھاتا ہے۔ |
| `show_percentage` | boolean | `true` | مصنوعی فیصد دکھاتا ہے۔ |
| `icon_tap_action` | action | `more-info` | آئیکن کو تھپتھپانے پر اضافی کارروائی |
| `always_show_icon_background` | boolean | `false` | ہمیشہ سرکلر آئیکن کا پس منظر دکھاتا ہے، یہاں تک کہ جب None icon_tap_action کے لیے منتخب کیا گیا ہو |

مکمل مثال:

```yaml
type: custom:smart-plug-multilevel-light-card
entity: light.floor_lamp
name: Торшер
icon: mdi:floor-lamp
show_mode: true
show_percentage: true
icon_tap_action:
  action: more-info
always_show_icon_background: false
```

<a id="yaml-lovelace-mode"></a>

### Lovelace وسائل YAML موڈ

> غالباً، آپ نے یہ موڈ فعال نہیں کیا ہے۔ اگر کوئی مسئلہ نہیں ہے اور کارڈ کام کرتا ہے، تو اس مرحلہ کو چھوڑ دیں۔

اگر آپ کے پاس ہے۔`configuration.yaml`واضح طور پر مقرر:

```yaml
lovelace:
  resource_mode: yaml
```

ہوم اسسٹنٹ انضمام کو وسائل کی فہرست کو خود بخود تبدیل کرنے کی اجازت نہیں دیتا ہے۔ اس صورت میں، وسائل کو دستی طور پر شامل کریں:

```yaml
lovelace:
  resource_mode: yaml
  resources:
    - url: /api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
      type: module
```

تبدیلی کے بعد، Lovelace وسائل کو دوبارہ شروع کریں یا ہوم اسسٹنٹ کو دوبارہ شروع کریں۔

/config/custom_components/smart_plug_multilevel_light/manifest.json

یہ متوقع رویہ ہے۔ قلیل مدتی بجلی کے اتار چڑھاو کو جعلی سوئچنگ کا سبب بننے سے روکنے کے لیے، انضمام صرف اسی نئے موڈ کے مطابق ہونے کے بعد مسلسل کئی ریڈنگز کے موڈ کو تبدیل کرتا ہے۔

تصدیق ہونے تک، انضمام پچھلے موڈ کو برقرار رکھتا ہے۔ اس کی بدولت، لیمپ کو سوئچ کرنے، اس کی طاقت کو مستحکم کرنے، یا سینسر کی ریڈنگ میں چھوٹے اتار چڑھاو کی وجہ سے کارڈ درمیانی اقدار کی وجہ سے موڈ کے درمیان سوئچ نہیں کرتا ہے۔

ریڈنگز کی تعداد کو کم کرنا نئے موڈ کے ڈسپلے کو تیز کرتا ہے، لیکن پتہ لگانے کو طاقت کے اتار چڑھاو کے لیے زیادہ حساس بناتا ہے۔

## 🗑 ہٹانا

1. تمام تخلیق کردہ مددگار اشیاء کو حذف کریں۔**اسمارٹ پلگ ملٹی لیول لائٹ**کے ذریع&#x6D2;**[ترتیبات → آلات اور خدمات → لوازمات](https://my.home-assistant.io/redirect/helpers/)**.

/config/custom_components/smart_plug_multilevel_light

/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
