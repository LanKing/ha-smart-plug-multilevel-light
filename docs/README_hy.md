# 🔌 Smart Plug Multi-Level Light

![Пример режимов на карточке](ha-smart-plug-multilevel-light-card-modes-v4.png)

**✨ Առանձնահատկություններ և առանձնահատկություններ.**

* Ստեղծում է տնային օգնականի բնիկ միավոր`light`համատեղելի ավտոմատացումների, սցենարների և ստանդարտ HA ինտերֆեյսի հետ;
* Ճիշտ է միացնում լամպը, անկախ նրանից, թե ինչպես է այն անջատվել. եթե հոսանքն անջատվել է խելացի վարդակից, այն պարզապես միացնում է այն. եթե լամպը անջատվել է սեփական կոճակով, երբ վարդակը միացված է եղել, ապա այն կատարում է էներգիայի անջատման և նորից միացման ցիկլ.
* Ավտոմատ կերպով որոշում է լամպի ընթացիկ աշխատանքային ռեժիմը՝ հիմնվելով փաստացի չափված կայուն հզորության վրա.
* Այն ունի պարզ կոնֆիգուրատոր, որում օգտագործողը հաջորդաբար անվանում է իր լամպի կողմից աջակցվող ռեժիմները, և համակարգը սովորում է՝ յուրաքանչյուր ռեժիմում կայուն հզորությունը որոշելով.
* Առաջին կարգաբերման ժամանակ հոսանքը կարդացվում է իրական ժամանակում. օգտատերը միայն պետք է միացնի լույսը հաջորդ ռեժիմին և սեղմի սովորելու կոճակը;
* Հաջողությամբ զտում է էներգիայի անկայուն ընթերցումները՝ կանխելով քարտի վրա ցուցիչի քաոսային փոփոխությունները, երբ հզորությունը «ցատկում» է մեկ ռեժիմում (և նույնիսկ համընկնում է հաջորդ ռեժիմի հետ);
* Աջակցում է կամայական թվով ռեժիմների;
* Քարտը կառուցված է ստանդարտ Home Assistant Tile Card-ի վրա՝ պահպանելով դրա երկրաչափությունը, ֆոնը, սավառնող էֆեկտները, չափերը, տպագրությունը և ստանդարտ գործողությունները:
* Քարտում ընթացիկ պայծառությունը տեսողականորեն կոդավորված է գույնի ինտենսիվությամբ.
* Պայծառությունը գծային հաշվարկում է առավելագույն հզորության նկատմամբ. հաշվարկված պայծառության կլորացումը մինչև 5% կարող է միացված լինել տոկոսների ավելի ճշգրիտ ցուցադրման համար.
* Թույլ է տալիս ճկուն կերպով հարմարեցնել ցուցադրվող պարամետրերը և քարտի տեսքը.
* Թույլ է տալիս ընտրել միայն ընտրված խելացի վարդակից հետ կապված էներգիայի սենսորը;
* Թույլ է տալիս հարմարեցնել անջատման ցիկլի հետաձգումը լամպերի և վարդակների տարբեր մոդելների հետ ճիշտ աշխատանքի համար.
* Թույլ է տալիս սահմանել հզորության շեմը, որից ցածր լամպը համարվում է անջատված.
* Ինտերֆեյսը տեղայնացված է Տնային օգնականի 64 տեղանքների համար:

## 🗜 Երկաթի պատրաստում

Ձեզ անհրաժեշտ կլինի.

2. Հիմար լույս, որն ավտոմատ կերպով միանում է միանալուց հետո և ունի պայծառության բազմաթիվ կարգավորումներ՝ լիարժեք վայելելու համար:

> Ես օգտագործել եմ վարդակից[Tuya TS011F (Girier դեպքում)](https://www.zigbee2mqtt.io/devices/TS011F_plug_3.html). Ասեմ, որ փորձերի սկզբում Girier շարքի վարդակները չեն տեղավորվում ոչ ճշգրիտ չափումների պատճառով, բայց այս մոդելը տեղավորվել է, չնայած այն նաև եղել է Girier-ի դեպքում։

### 🧑‍💻 Տեղադրում առանց HACS-ի

1. Պահեստի էջում սեղմեք**Կոդ → Ներբեռնեք ZIP**.

custom_components/smart_plug_multilevel_light

/config/custom_components/smart_plug_multilevel_light/manifest.json

### 🎨 Վիզուալ էֆեկտներ

#### Կարգավորումներ քարտում

Բացեք վահանակը, որտեղ գտնվում է քարտը, անցեք խմբագրման ռեժիմ և սեղմեք**Խմբագրել**ցանկալի քարտի վրա:

Բաժնի բացում**Բովանդակություն (Content)**, կտեսնեք հասանելի կարգավորումները.

* **Ցույց տալ ռեժիմի անունը (Show mode name)**— ցույց է տալիս կամ թաքցնում ընթացիկ ռեժիմի անունը՝ օրինակ՝ Dim, Low, Medium կամ High:
* **Ցույց տալ տոկոսը (Show percentage)**— ցույց է տալիս կամ թաքցնում հաշվարկված պայծառությունը որպես տոկոս:

Բաժնի բացում**Փոխազդեցություններ (Interactions)**, կտեսնեք.

* **Միշտ ցույց տալ պատկերակի ֆոնը (Always show icon background)**— պահպանում է պատկերակի շուրջ կլոր ֆոնը, նույնիսկ եթե դրա համար առանձին գործողություն անջատված է:

> 🚫 Ի դեպ, եթե դուք, ինչպես ես, օգտագործում եք ոչ ստանդարտ քարտի պատկերակ, և երբ այն անջատված է, այն տեսողականորեն խաչված չէ, խորհուրդ եմ տալիս իմ մյուս փլագինը.[Mdi Off Fallback](https://github.com/LanKing/ha-mdi-off-fallback/blob/main/docs/README_hy.md), որը լուծում է այս գեղագիտական ​​խնդիրը։

#### Պայծառությունը կլորացվում է մինչև 5%

Բա&#x581;**[Կարգավորումներ → Սարքեր և ծառայություններ → Աքսեսուարներ](https://my.home-assistant.io/redirect/helpers/)**, գտեք ավելի վաղ ստեղծված օգնական օբյեկտը**Smart Plug Multi-Level Light**և բացեք դրա կարգավորումները: Միացնել կամ անջատել**Round brightness to 5% (may look nicer)**.

Երբ կարգավորումը միացված է, հաշվարկված տոկոսը կլորացվում է մինչև մոտակա 5%, օրինակ՝ 33% → 35%, 67% → 65%։

Կլորացումը ազդում է միայն քարտի ցուցադրվող տոկոսի և տեսողական ինտենսիվության վրա: Լամպի ռեժիմի սահմանումը և շահագործումը չեն փոխվում: Լռելյայնորեն, կլորացումն անջատված է:

## 🧩 Lovelace բացիկը մանրամասն

Հասանելի ընտրանքներ.

| Պարամետր | Տեսակ | Կանխադրված | Նկարագրություն |
|---|---|---:|---|
| `entity` | string | պահանջվում է | ինտեգրման արդյունքում ստեղծված սուբյեկտ |
| `name` | string | կազմակերպության անվանումը | անտեսում է քարտի վրա նշված անունը |
| `icon` | string | էության պատկերակը | անտեսում է պատկերակը |
| `show_mode` | boolean | `true` | ցույց է տալիս ռեժիմի անունը |
| `show_percentage` | boolean | `true` | ցույց է տալիս սինթետիկ տոկոսը |
| `icon_tap_action` | action | `more-info` | լրացուցիչ գործողություն, երբ պատկերակը հպվում է |
| `always_show_icon_background` | boolean | `false` | միշտ ցույց է տալիս շրջանաձև պատկերակի ֆոնը, նույնիսկ երբ None-ն ընտրված է icon_tap_action-ի համար |

Ամբողջական օրինակ.

```yaml
type: custom:smart-plug-multilevel-light-card
entity: light.floor_lamp
name: Торшер
icon: mdi:floor-lamp
show_mode: true
show_percentage: true
icon_tap_action:
  action: more-info
always_show_icon_background: false
```

### Lovelace ռեսուրս YAML ռեժիմ

> Ամենայն հավանականությամբ, դուք այս ռեժիմը միացված չեք: Եթե ​​խնդիրներ չկան, և քարտն աշխատում է, բաց թողեք այս քայլը:

Եթե ​​ունեք`configuration.yaml`հստակորեն սահմանված է.

```yaml
lovelace:
  resource_mode: yaml
```

Home Assistant-ը թույլ չի տալիս ինտեգրումը ավտոմատ կերպով փոխել ռեսուրսների ցանկը: Այս դեպքում ձեռքով ավելացրեք ռեսուրսը.

```yaml
lovelace:
  resource_mode: yaml
  resources:
    - url: /api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
      type: module
```

Փոփոխությունից հետո վերագործարկեք Lovelace ռեսուրսները կամ վերագործարկեք Home Assistant-ը:

## 🧯 Անսարքությունների վերացում

<details>
<summary><b>❓Ինտեգրումը չի հայտնվում օգնականների ցանկում</b></summary>
<br />

**Հավանական պատճառ.**&#x57D;խալ ուղի կամ Home Assistant-ը չի վերագործարկվել:

Ստուգեք ֆայլի առկայությունը.

```text
/config/custom_components/smart_plug_multilevel_light/manifest.json
```

Այնուհետև ամբողջությամբ վերագործարկեք Home Assistant-ը և ստուգեք գրանցամատյանը սխալների համար`smart_plug_multilevel_light`.

<hr />
</details>

<details>
<summary><b>❓Խցանների ցանկը դատարկ է</b></summary>
<br />

Ինտեգրումը ցույց է տալիս միայն օբյեկտները`switch`կապված սարքերի հետ, որոնք նաև տրամադրում են ներառված սենսոր`device_class: power`.

Ստուգու&#x574;**[Կարգավորումներ → Սարքեր և ծառայություններ → Օբյեկտներ](https://my.home-assistant.io/redirect/entities/)**:

* Պատկանո՞ւմ են`switch`իսկ ուժային սենսոր մեկ սարքի համար?
* Արդյո՞ք հոսանքի սենսորը միացված է:
* Ճի՞շտ է նշված։`device_class`?
* Արդյո՞ք այն ունի թվային վիճակ:

<hr />
</details>

<details>
<summary><b>❓Ստեղծումը դադարում է էներգիայի սենսորի բացակայող հաղորդագրությամբ</b></summary>
<br />

Ելք ընտրելուց հետո ինտեգրումը կրկին ստուգում է հոսանքի սենսորի առկայությունը: Սխալը տեղի է ունենում, եթե սենսորը հեռացվել է, անջատվել է, տեղափոխվել այլ սարք կամ այլևս չկա`device_class: power`.

<hr />
</details>

<details>
<summary><b>❓Լամպը ցուցադրվում է որպես Անջատված, երբ վարդակից միացված է</b></summary>
<br />

Ստուգեք հզորության սենսորի արժեքը: Վիրտուալ լամպը համարվում է անջատված, երբ`0 W`; երբ դրական է, այն պետք է սահմանվի որպես`on`.

<hr />
</details>

<details>
<summary><b>❓Լամպը ցուցադրվում է որպես Միացված, երբ այն ֆիզիկապես անջատված է</b></summary>
<br />

Ստուգեք, որ ընտրված հզորության սենսորն իրականում ցույց է տալիս`0 W`, երբ լամպը անջատվում է սեփական կոճակով։

<hr />
</details>

<details>
<summary><b>❓Սխալ ռեժիմ է հայտնաբերվել</b></summary>
<br />

Ստուգեք**🐞 Last measures**պարամետրերում և ատրիբուտներում`power_history`,`power_history_modes`,`power_sample_interval_seconds`Եվ`selected_power_mode`.`power_history`ցույց է տալիս վերջին գրանցված հզորության արժեքները,`power_history_modes`— ռեժիմ նրանցից յուրաքանչյուրի համար՝ ըստ կազմաձևված շեմերի,`power_sample_interval_seconds`պարբերական ամրագրման միջակայքն է, և`selected_power_mode`— ընթացիկ հաստատված ռեժիմ:

<hr />
</details>

<details>
<summary><b>❓Ռեժիմի փոփոխությունները անմիջապես չեն ցուցադրվում</b></summary>
<br />

Սա սպասելի պահվածք է։ Որպեսզի էլեկտրաէներգիայի կարճաժամկետ տատանումները կեղծ միացում չառաջացնեն, ինտեգրումը փոխում է ռեժիմը միայն այն բանից հետո, երբ մի քանի հաջորդական ընթերցումներ համապատասխանում են նույն նոր ռեժիմին:

Ընթերցումների անհրաժեշտ քանակը սահմանվում է պարամետրով**Consecutive readings to switch**և լռելյայն է`5`. Պարբերական չափումները կատարվում են վայրկյանում մեկ անգամ, և սենսորային վիճակի փոփոխություններն անմիջապես մշակվում են: Եթե ​​փորձարկման ժամանակ արժեքը համապատասխանում է այլ ռեժիմի, հետհաշվարկը նորից սկսվում է:

Մինչև հաստատումը, ինտեգրումը պահպանում է նախորդ ռեժիմը: Դրա շնորհիվ քարտը չի անցնում ռեժիմների միջև միջանկյալ արժեքների պատճառով, որոնք առաջանում են լամպը միացնելիս, դրա հզորությունը կայունացնելիս կամ սենսորային ընթերցումների փոքր տատանումներից:

Ընթերցումների քանակի կրճատումն արագացնում է նոր ռեժիմի ցուցադրումը, սակայն հայտնաբերումը դարձնում է ավելի զգայուն հոսանքի տատանումների նկատմամբ:

<hr />
</details>

<details>
<summary><b>❓Քարտը չի հայտնվում ցուցակում</b></summary>
<br />

Ավտոմատ գրանցումը տեղի է ունենում միայն առնվազն մեկ կազմաձևված օգնական օբյեկտ բեռնելուց հետո և միայն ռեսուրսների ռեժիմում`storage`. Ինտեգրման տեղադրման եղանակը՝ HACS-ի միջոցով կամ ձեռքով, չի ազդում դրա վրա:

Ստուգե&#x584;**[Կարգավորումներ → Վահանակներ → ⋮ → Ռեսուրսներ](https://my.home-assistant.io/redirect/lovelace_resources/)**. URL-ը պետք է լինի այնտեղ.

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

YAML ռեժիմում[ավելացնել ռեսուրսը ձեռքով](#yaml-lovelace-mode).

<hr />
</details>

<details>
<summary><b>❓Հին քարտը դեռ ցուցադրվում է թարմացումից հետո</b></summary>
<br />

1. Ամբողջովին վերագործարկեք Home Assistant-ը:
2. Թարմացրեք էջը՝ ձեր բրաուզերի քեշը մաքրելու համար:
3. Ստուգեք տարբերակի համարը վահանակի ռեսուրսի URL-ում:
4. Բջջային հավելվածում ամբողջովին փակեք և նորից բացեք ինտերֆեյսը:

<hr />
</details>

## 🗑 Հեռացում

1. Ջնջել բոլոր ստեղծված օգնական օբյեկտները**Smart Plug Multi-Level Light**միջոցո&#x57E;**[Կարգավորումներ → Սարքեր և ծառայություններ → Աքսեսուարներ](https://my.home-assistant.io/redirect/helpers/)**.
2. Հեռացրեք ինտեգրումը HACS-ի միջոցով կամ ձեռքով ջնջեք թղթապանակը.

```text
/config/custom_components/smart_plug_multilevel_light
```

3. Ստուգե&#x584;**[Կարգավորումներ → Վահանակներ → ⋮ → Ռեսուրսներ](https://my.home-assistant.io/redirect/lovelace_resources/)**&#x587; ձեռքով ջնջեք քարտի ռեսուրսը, եթե այն մնա.

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

4. Ամբողջովին վերագործարկեք Home Assistant-ը:
5. Անհրաժեշտության դեպքում թարմացրեք էջը՝ ինտերֆեյսի քեշը մաքրելու համար:
