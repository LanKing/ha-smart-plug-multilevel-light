# 🔌 ปลั๊กไฟอัจฉริยะหลายระดับ

![Пример режимов на карточке](https://raw.githubusercontent.com/LanKing/ha-smart-plug-multilevel-light/main/docs/ha-smart-plug-multilevel-light-card-modes-v4.png)

**✨คุณสมบัติและคุณสมบัติ:**

* สร้างเอนทิตี Home Assistant ดั้งเดิม`light`เข้ากันได้กับระบบอัตโนมัติ สคริปต์ และอินเทอร์เฟซ HA มาตรฐาน
* เปิดหลอดไฟอย่างถูกต้องไม่ว่าจะปิดด้วยวิธีใดก็ตาม: หากปิดไฟผ่านปลั๊กไฟอัจฉริยะ หลอดไฟก็จะเปิดขึ้นมาทันที หากหลอดไฟถูกปิดด้วยปุ่มของตัวเองในขณะที่ซ็อกเก็ตเปิดอยู่หลอดไฟจะทำการปิดวงจรและเปิดอีกครั้ง
* กำหนดโหมดการทำงานปัจจุบันของหลอดไฟโดยอัตโนมัติตามกำลังไฟที่เสถียรที่วัดได้จริง
* มีตัวกำหนดค่าอย่างง่ายซึ่งผู้ใช้ตั้งชื่อโหมดต่างๆ ที่หลอดไฟรองรับตามลำดับ และระบบจะเรียนรู้โดยการกำหนดพลังงานที่เสถียรในแต่ละโหมด
* ในระหว่างการตั้งค่าครั้งแรก พลังงานจะถูกอ่านแบบเรียลไทม์: ผู้ใช้เพียงแค่ต้องเปลี่ยนไฟไปที่โหมดถัดไปแล้วกดปุ่มการเรียนรู้
* กรองการอ่านค่าพลังงานที่ไม่เสถียรออกได้สำเร็จ ป้องกันการเปลี่ยนแปลงตัวบ่งชี้บนการ์ดที่วุ่นวายเมื่อพลังงาน "กระโดด" ภายในโหมดเดียว (และยังเกิดขึ้นพร้อมกันกับโหมดถัดไป)
* รองรับโหมดจำนวนเท่าใดก็ได้
* การ์ดนี้สร้างขึ้นจากการ์ด Home Assistant Tile มาตรฐาน โดยคงรูปทรง พื้นหลัง เอฟเฟกต์โฮเวอร์ ขนาด ตัวอักษร และการดำเนินการมาตรฐาน
* ในการ์ด ความสว่างปัจจุบันจะถูกเข้ารหัสด้วยความเข้มของสี
* คำนวณความสว่างเชิงเส้นสัมพันธ์กับกำลังสูงสุด สามารถเปิดใช้งานการปัดเศษของความสว่างที่คำนวณได้เป็น 5% เพื่อการแสดงเปอร์เซ็นต์ที่แม่นยำยิ่งขึ้น
* ช่วยให้คุณปรับแต่งพารามิเตอร์ที่แสดงและรูปลักษณ์ของการ์ดได้อย่างยืดหยุ่น
* ให้คุณเลือกเฉพาะเซ็นเซอร์พลังงานที่เกี่ยวข้องกับปลั๊กอัจฉริยะที่เลือก
* ช่วยให้คุณปรับความล่าช้าของวงจรการลดพลังงานเพื่อการทำงานที่ถูกต้องกับหลอดไฟและเต้ารับรุ่นต่างๆ
* ช่วยให้คุณตั้งค่าเกณฑ์พลังงานด้านล่างซึ่งถือว่าหลอดไฟปิดอยู่
* อินเทอร์เฟซได้รับการแปลเป็นภาษาท้องถิ่นสำหรับ 64 ภาษาของ Home Assistant

## 🗜 เตรียมเหล็ก

คุณจะต้องการ:

1. ซ็อกเก็ตอัจฉริยะที่ควรให้การควบคุมพลังงาน (สวิตช์) และการวัดพลังงาน (เซ็นเซอร์ที่มี device\_class: พลังงาน) ให้กับ HA เอนทิตีทั้งสองจะต้องอยู่ในอุปกรณ์เดียวกันและเปิดใช้งานได้
2. ไฟโง่ๆ ที่เปิดอัตโนมัติเมื่อเสียบปลั๊กและมีการตั้งค่าความสว่างหลายระดับเพื่อความเพลิดเพลินที่สมบูรณ์

> ฉันใช้ซ็อกเก็ต[Tuya TS011F (ในกรณี Girier)](https://www.zigbee2mqtt.io/devices/TS011F_plug_3.html). ฉันจะบอกว่าในช่วงเริ่มต้นของการทดลอง ซ็อกเก็ตซีรีส์ Girier ไม่พอดีเนื่องจากการวัดที่ไม่ถูกต้อง แต่รุ่นนี้ทำได้ แม้ว่าจะอยู่ในกรณี Girier ด้วยก็ตาม

### 🎨 เอฟเฟ็กต์ภาพ

#### การตั้งค่าในการ์ด

เปิดแผงที่มีการ์ดอยู่ ไปที่โหมดแก้ไขแล้วคลิก**แก้ไข**บนการ์ดที่ต้องการ

การเปิดส่วน**เนื้อหา (Content)**คุณจะเห็นการตั้งค่าที่ใช้ได้:

* **แสดงชื่อโหมด (Show mode name)**— แสดงหรือซ่อนชื่อของโหมดปัจจุบัน: เช่น หรี่ ต่ำ ปานกลาง หรือสูง
* **แสดงเปอร์เซ็นต์ (Show percentage)**— แสดงหรือซ่อนความสว่างที่คำนวณได้เป็นเปอร์เซ็นต์

การเปิดส่วน**การโต้ตอบ (Interactions)**คุณจะเห็น:

* **แสดงพื้นหลังไอคอนเสมอ (Always show icon background)**— คงพื้นหลังทรงกลมรอบๆ ไอคอนไว้ แม้ว่าการดำเนินการแยกต่างหากสำหรับไอคอนนั้นจะถูกปิดใช้งานก็ตาม

> 🚫 อย่างไรก็ตาม หากคุณชอบฉันใช้ไอคอนการ์ดที่ไม่ได้มาตรฐาน และเมื่อปิดแล้วจะไม่ถูกขีดฆ่า ฉันขอแนะนำปลั๊กอินอื่นของฉัน -[Mdi ปิดทางเลือก](https://github.com/LanKing/ha-mdi-off-fallback/blob/main/docs/README_th.md)ซึ่งช่วยแก้ปัญหาด้านสุนทรียภาพนี้

#### ความสว่างปัดเศษขึ้นถึง 5%

เปิ&#xE14;**[การตั้งค่า → อุปกรณ์และบริการ → อุปกรณ์เสริม](https://my.home-assistant.io/redirect/helpers/)**&#xE43;ห้ค้นหาวัตถุตัวช่วยที่สร้างขึ้นก่อนหน้านี้**ปลั๊กไฟอัจฉริยะหลายระดับ**และเปิดการตั้งค่า เปิดหรือปิด**Round brightness to 5% (may look nicer)**.

เมื่อเปิดใช้งานการตั้งค่า เปอร์เซ็นต์ที่คำนวณได้จะถูกปัดเศษเป็น 5% ที่ใกล้ที่สุด เช่น 33% → 35%, 67% → 65%

การปัดเศษจะส่งผลต่อเปอร์เซ็นต์ที่แสดงและความเข้มของการมองเห็นของการ์ดเท่านั้น คำจำกัดความของโหมดและการทำงานของหลอดไฟไม่เปลี่ยนแปลง ตามค่าเริ่มต้น การปัดเศษจะถูกปิดใช้งาน

## 🧩 การ์ดเลิฟเลซแบบละเอียด

ตัวเลือกที่มี:

| พารามิเตอร์ | ประเภท | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---:|---|
| `entity` | string | จำเป็น | เอนทิตีที่สร้างขึ้นโดยการบูรณาการ |
| `name` | string | ชื่อเอนทิตี | แทนที่ชื่อที่แสดงบนการ์ด |
| `icon` | string | ไอคอนเอนทิตี | แทนที่ไอคอน |
| `show_mode` | boolean | `true` | แสดงชื่อโหมด |
| `show_percentage` | boolean | `true` | แสดงเปอร์เซ็นต์การสังเคราะห์ |
| `icon_tap_action` | action | `more-info` | การดำเนินการเพิ่มเติมเมื่อแตะไอคอน |
| `always_show_icon_background` | boolean | `false` | จะแสดงพื้นหลังไอคอนวงกลมเสมอ แม้ว่าจะเลือก None สำหรับ icon_tap_action แล้วก็ตาม |

ตัวอย่างเต็ม:

```yaml
type: custom:smart-plug-multilevel-light-card
entity: light.floor_lamp
name: Торшер
icon: mdi:floor-lamp
show_mode: true
show_percentage: true
icon_tap_action:
  action: more-info
always_show_icon_background: false
```

<a id="yaml-lovelace-mode"></a>

### โหมด YAML ทรัพยากร Lovelace

> เป็นไปได้มากว่าคุณไม่ได้เปิดใช้งานโหมดนี้ หากไม่มีปัญหาใดๆ และการ์ดใช้งานได้ ให้ข้ามขั้นตอนนี้

ถ้าคุณมี`configuration.yaml`กำหนดไว้อย่างชัดเจน:

```yaml
lovelace:
  resource_mode: yaml
```

Home Assistant ไม่อนุญาตให้บูรณาการการเปลี่ยนแปลงรายการทรัพยากรโดยอัตโนมัติ ในกรณีนี้ ให้เพิ่มทรัพยากรด้วยตนเอง:

```yaml
lovelace:
  resource_mode: yaml
  resources:
    - url: /api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
      type: module
```

หลังจากการเปลี่ยนแปลง ให้รีบูตทรัพยากร Lovelace หรือรีสตาร์ท Home Assistant

<summary><b>❓การเปลี่ยนแปลงโหมดจะไม่แสดงทันที</b></summary>
<br />

นี่คือลักษณะการทำงานที่คาดหวัง เพื่อป้องกันความผันผวนของพลังงานในระยะสั้นทำให้เกิดการสลับปลอม การบูรณาการจะเปลี่ยนโหมดหลังจากการอ่านค่าติดต่อกันหลายครั้งเท่านั้นที่สอดคล้องกับโหมดใหม่เดียวกัน

จำนวนการอ่านที่ต้องการถูกกำหนดโดยพารามิเตอร์**Consecutive readings to switch**และค่าเริ่มต้นเป็น`5`. การวัดเป็นระยะจะดำเนินการหนึ่งครั้งต่อวินาที และการเปลี่ยนแปลงสถานะเซ็นเซอร์จะถูกประมวลผลทันที หากในระหว่างการทดสอบค่าสอดคล้องกับโหมดอื่น การนับถอยหลังจะเริ่มต้นอีกครั้ง

จนกว่าจะมีการยืนยัน การผสานรวมจะคงโหมดก่อนหน้าไว้ ด้วยเหตุนี้การ์ดจึงไม่สลับระหว่างโหมดต่างๆ เนื่องจากค่ากลางที่เกิดขึ้นเมื่อเปลี่ยนหลอดไฟ ทำให้พลังงานคงที่ หรือความผันผวนเล็กน้อยในการอ่านเซ็นเซอร์

การลดจำนวนการอ่านจะทำให้การแสดงผลของโหมดใหม่เร็วขึ้น แต่ทำให้การตรวจจับมีความไวต่อความผันผวนของพลังงานมากขึ้น

</details>

<summary><b>❓การ์ดไม่ปรากฏในรายการ</b></summary>
<br />

การลงทะเบียนอัตโนมัติจะเกิดขึ้นหลังจากโหลดออบเจ็กต์ตัวช่วยที่กำหนดค่าไว้อย่างน้อยหนึ่งรายการและเฉพาะในโหมดทรัพยากรเท่านั้น`storage`. วิธีการติดตั้งการรวมระบบ - ผ่าน HACS หรือด้วยตนเอง - ไม่มีผลกับสิ่งนี้

ตรวจสอ&#xE1A;**[การตั้งค่า → แผง → ⋮ → ทรัพยากร](https://my.home-assistant.io/redirect/lovelace_resources/)**. URL ควรอยู่ที่นั่น:

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

ในโหมด YAML[เพิ่มทรัพยากรด้วยตนเอง](#yaml-lovelace-mode).

</details>

<details>
<summary><b>❓การ์ดเก่ายังคงแสดงอยู่หลังจากการอัพเดต</b></summary>
<br />

1. รีสตาร์ท Home Assistant โดยสมบูรณ์
2. รีเฟรชหน้าเพื่อล้างแคชของเบราว์เซอร์ของคุณ
3. ตรวจสอบหมายเลขเวอร์ชันใน URL ทรัพยากรของแผง
4. ในแอปพลิเคชันมือถือ ให้ปิดและเปิดอินเทอร์เฟซใหม่ทั้งหมด

</details>

## 🗑 การถอด

1. ลบวัตถุตัวช่วยที่สร้างขึ้นทั้งหมด**ปลั๊กไฟอัจฉริยะหลายระดับ**ผ่า&#xE19;**[การตั้งค่า → อุปกรณ์และบริการ → อุปกรณ์เสริม](https://my.home-assistant.io/redirect/helpers/)**.
2. ลบการรวมผ่าน HACS หรือลบโฟลเดอร์ด้วยตนเอง:

```text
/config/custom_components/smart_plug_multilevel_light
```

3. ตรวจสอ&#xE1A;**[การตั้งค่า → แผง → ⋮ → ทรัพยากร](https://my.home-assistant.io/redirect/lovelace_resources/)**&#xE41;ละลบทรัพยากรการ์ดด้วยตนเองหากยังคงอยู่:

```text
/api/smart_plug_multilevel_light/smart-plug-multilevel-light-card.js?v=0.10.9
```

4. รีสตาร์ท Home Assistant โดยสมบูรณ์
5. หากจำเป็น ให้รีเฟรชเพจเพื่อล้างแคชของอินเทอร์เฟซ
